1. 평가 프로토콜 변경 
F1@1.5s로 고정된 평가지표에서 Rel.Dis F1으로 변경하기
이를 통해 기존 모델 평가와 게임 데이터셋에서 평가 지표를 비교 할 수 있게 된다.
즉, Kinetics-400, TAPOS에서 높은 평가를 보이던 GEBD 모델들이 게임 데이터셋에서는 높은 score를 얻지 못한다.는 것을 확인할 수 있게 된다.

하지만 이 결과가 모델의 문제인가? 라고 했을 때, Boundary의 기준이 다르기 때문에 발생하는 문제라고도 볼 수 있다. 즉, 기존의 GEBD 모델을 활용하는 것은 무리가 있다!

GEBD 모델을 Fusion하는게 아니라 Video Feature 모델을 뽑아서 마찬가지로 novelty score를 뽑고 Fusion하기? -> 이거는 아닌 듯, GEBD가 시각적 경계 가능성을 뽑아주니까 그냥 활용할 수 있음.

2. 다른 데이터셋 활용하기?
이거는 모르겠음
같은 평가지표로 비교만 하기.
이걸로 일반 데이터셋에서 잘 동작해도 게임 데이터셋에서는 제대로 동작하지 못한다를 보여주기!
반대로 우리의 모델을 일반 데이터셋에 적용했을 때, 제대로 동작하지 않는다? 게임의 오디오가 경계와 관련있다는 근거로 쓸 수 있음.


3. 지금은 그냥 더해서 처리했었는데, DDM-net의 probability는 score와 같은 의미를 가지는 것이 아니다.
	- 오디오가 검출한 것과 비디오가 검출한 것을 독립적으로 처리하고 합치는 식으로 하는게 옳다고 생각이 든다.

그래서 새롭게 진행한 Fusion 방식

| 구분  | 방법                                        | 학습 여부                 | 핵심 아이디어                                                       | 결과 요약                                  |
| --- | ----------------------------------------- | --------------------- | ------------------------------------------------------------- | -------------------------------------- |
| 1   | **Audio-only stem weighted fusion**       | 없음                    | SFX + Mixture + Music + Speech를 고정 가중치로 합산                    | 가장 안정적인 baseline                       |
| 2   | **Audio + DDM score fusion**              | 없음                    | audio score에 DDM-Net boundary probability를 가중합                | Macro 기준 최고권                           |
| 3   | **DDM gated rescue**                      | 없음                    | audio가 놓친 곳에서 DDM이 강할 때만 rescue                               | 큰 개선 없음                                |
| 4   | **DDM prediction / rescue cap**           | 없음                    | DDM rescue 개수를 제한해서 FP 억제                                     | 큰 개선 없음                                |
| 5   | **w_DDM / k / peak distance grid fusion** | 없음, valid grid search | DDM weight, adaptive threshold, peak distance를 valid에서 선택     | DDM fusion 중 가장 안정적                    |
| 6   | **Audio + ResNet novelty fusion**         | 없음, valid grid search | audio score + ResNet visual novelty score                     | Micro 기준 최고권, Macro는 DDM fusion과 거의 동률 |
| 7   | **Candidate Logistic Regression + DDM**   | 있음                    | candidate boundary를 만들고 audio/DDM feature로 재점수화               | audio-only보다 낮음                        |
| 8   | **Candidate Random Forest + DDM**         | 있음                    | candidate-level RF reranker                                   | 낮음                                     |
| 9   | **Dense frame-level MLP fusion**          | 있음                    | frame/time-bin 단위로 audio/DDM feature를 분류                      | audio-only보다 낮음                        |
| 10  | **5-dim windowed MLP**                    | 있음                    | local window score feature로 boundary 분류                       | audio-only보다 낮음                        |
| 11  | **TinyMLP combined audio+ResNet**         | 있음                    | weighted audio score + ResNet novelty를 candidate reranker에 입력 | 낮음                                     |
| 12  | **TinyMLP separate stems + ResNet**       | 있음                    | mixture/sfx/music/speech를 따로 입력                               | combined보다 더 낮음                        |
| 13  | **TinyMLP soft label / hard negative**    | 있음                    | label imbalance 완화, GT 거리 기반 soft label                       | 개선 없음                                  |
근데 weight를 쓰는 method들이 full-tuning이라 불공정한 비교였음.
