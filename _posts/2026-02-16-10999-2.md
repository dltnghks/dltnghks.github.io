[10999번 구간 합 구하기 2](https://www.acmicpc.net/problem/10999)

## 어떤 걸 사용하나??
구간 합 질의 + 구간 값 증가 갱신이 함께 나오므로 `세그먼트 트리 + Lazy Propagation`을 사용한다.

- 일반 세그트리만 쓰면 구간 갱신마다 하위 노드를 모두 내려가야 해서 느리다.
- Lazy 배열에 "나중에 반영할 값"을 저장해 두면, 필요한 시점에만 전파해서 `O((M+K) log N)`으로 처리할 수 있다.

  - Lazy 사용: 각 연산 O(log N)
  - Lazy 미사용: 구간 업데이트가 최악 O(N), 구간 합 질의 O(log N) 또는 구현에 따라 O(N)

## 어떻게 구현하나??
1. 트리 노드에는 해당 구간의 합을 저장한다.
2. `lazy[node]`는 아직 자식으로 내리지 않은 "구간 증가량"이다.
3. `push(node, l, r)`:
   - `lazy[node]`가 있으면 현재 노드 합에 `(r-l+1) * lazy[node]`를 반영한다.
   - 리프가 아니면 자식 lazy에 더해 준다.
   - 현재 lazy는 0으로 초기화한다.
4. 구간 갱신 시 범위가 완전히 포함되면 lazy만 더하고 즉시 propagate 한다.
5. 구간 합 질의 시에도 먼저 propagate 한 뒤, 겹치는 구간만 재귀적으로 합친다.

```cpp
#include <iostream>
#include <vector>

using namespace std;

int n, m, k;
vector<long long> numbers;
vector<long long> tree;
vector<long long> lazy;

long long MakeTree(int cur, int left, int right){
    if(left == right){
        tree[cur] = numbers[left];
        return tree[cur];
    }

    int mid = (left + right) / 2;
    tree[cur] = MakeTree(cur * 2, left, mid) + MakeTree(cur * 2 + 1, mid+1, right);

    return tree[cur];
}

void Push(int cur, int left, int right){
    if(lazy[cur] == 0){
        return;
    }

    tree[cur] += (right - left + 1) * lazy[cur];
    if(left != right){
        lazy[cur * 2] += lazy[cur];
        lazy[cur * 2 + 1] += lazy[cur];
    }
    lazy[cur] = 0;
}

void Change(int cur, int left, int right, int targetL, int targetR, long long num){
    Push(cur, left, right);

    if(right < targetL || targetR < left){
        return;
    }

    if(targetL <= left && right <= targetR){
        lazy[cur] += num;
        Push(cur, left, right);
        return;
    }

    int mid = (left + right) / 2;
    Change(cur * 2, left, mid, targetL, targetR, num);
    Change(cur * 2 + 1, mid+1, right, targetL, targetR, num);
    tree[cur] = tree[cur * 2] + tree[cur * 2 + 1];
}

long long Solve(int cur, int left, int right, int targetL, int targetR){
    Push(cur, left, right);

    if(right < targetL || targetR < left){
        return 0;
    }

    if(targetL <= left && right <= targetR){
        return tree[cur];
    }

    int mid = (left + right) / 2;
    return Solve(cur * 2, left, mid, targetL ,targetR) + Solve(cur * 2 + 1, mid+1, right, targetL ,targetR);
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    cout.tie(NULL);

    cin >> n >> m >> k;
    numbers = vector<long long>(n+1);
    tree = vector<long long>((4 * n) + 1, 0);
    lazy = vector<long long>((4 * n) + 1, 0);

    for(int i = 1; i <= n; i++){
        cin >> numbers[i];        
    }

    MakeTree(1, 1, n);

    for(int i = 0; i < m + k; i++){
        int a, b, c;
        cin >> a >> b >> c;
        if(a == 1){
            long long d;
            cin >> d;
            Change(1, 1, n, b, c, d);
        }
        else if(a == 2){
            cout << Solve(1, 1, n, b, c) << '\n';
        }
    }
    
    return 0;
}
```
