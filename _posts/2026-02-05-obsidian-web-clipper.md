기본 템플릿을 통해 Content는 가져오는데, 이걸 외부 AI를 통해서 어떻게 요약하고 정리를 하는거지?

{% raw %}
노트 내용을 이런 식으로 입력. {{}}안의 내용이 변수처리된다.

```
### 🔍 주요 연구 내용

#### 1. 연구 목적 (Research Question)

{{"* 이 논문이 해결하려고 하는 문제는 무엇인가?"}}
{{"* 기존 연구와의 차별점은?"}}

#### 2. 방법론 (Methodology)

{{"* 어떤 데이터셋이나 실험 환경을 사용했는가?"}}
{{"* 핵심 알고리즘이나 모델 구조:"}}


#### 3. 결과 및 결론 (Results)

{{"* 수치적 성능 향상이나 발견한 핵심 인사이트(예: 기존 대비 성능 **15%** 향상)"}}
```


인터프리터 컨텍스트에 이렇게 입력하면 해당 내용들이 변수로 처리되서 위의 내용에 추가가 된다.
```
본 문의 내용은 {{content}}이야.
그리고 주요 키워드는 영어를 사용하되, 전반적으로 한국어로 작성해줘.
{{"3줄 요약"}}을 해주고, 주요 태그를 찾아 {{"tags"|snake}}로 정의해줘.
{{"* 이 논문이 해결하려고 하는 문제는 무엇인가?"}}
{{"* 기존 연구와의 차별점은?"}}
{{"* 어떤 데이터셋이나 실험 환경을 사용했는가?"}}
{{"* 핵심 알고리즘이나 모델 구조:"}}
{{"* 수치적 성능 향상이나 발견한 핵심 인사이트(예: 기존 대비 성능 **15%** 향상)"}}

```
