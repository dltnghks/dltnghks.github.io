> 컴퓨터는 프로그램과 데이터를 저장장치, 메모리에서 가져와 CPU가 처리하고,
> 그 결과를 화면, 네트워크, 파일 등의 입출력 장치로 전달하는 시스템이다.

## 1. 전체 흐름
프로그램과 입력 데이터는 저장장치에 보관되거나 입출력 장치에서 들어온다.
실행이 시작되면 운영체제는 필요한 프로그램과 데이터를 메모리(RAM)에 올린다.
CPU는 메모리의 명령어와 데이터를 가져와 처리하고, 결과를 메모리, 저장장치, 출력 장치에 기록한다.


## 2. 핵심 구성 요소

| 구성 요소 | 역할 |
| --- | --- |
| 프로그램·입력 | CPU가 실행할 명령어와 처리할 데이터의 출발점 |
| 저장장치 | 전원이 꺼져도 파일과 프로그램을 보관하는 공간 |
| 메모리(RAM) | 실행 중인 프로그램과 데이터를 임시로 두는 작업 공간 |
| 캐시 | CPU가 자주 쓰는 데이터를 RAM보다 빠르게 제공하는 공간 |
| CPU | 명령어를 읽고 판단하고 계산하는 중심 장치 |
| 제어장치 | 명령어를 해석하고 각 장치의 동작을 조정 |
| 레지스터 | CPU 내부에서 값을 매우 빠르게 잠시 보관 |
| ALU | 덧셈·뺄셈·비교·논리 연산 수행 |
| 입출력(I/O) | 키보드·화면·디스크·네트워크 등 외부 장치와 연결 |
| 시스템 버스 | CPU, 메모리, 입출력 장치 사이에 데이터·주소·제어 신호를 전달 |

## 3. CPU의 반복 동작: 명령어 사이클
1. 명령어 인출: 메모리에서 다음 명령어를 가져온다.
2. 해독: 제어장치가 명령어의 의미를 판단한다.
3. 실행: ALU나 다른 장치가 필요한 연산을 수행한다.
4. 결과 저장: 결과를 레지스터나 메모리에 저장한다.

이 과정은 프로그램이 끝날 때까지 매우 빠르게 반복된다.
