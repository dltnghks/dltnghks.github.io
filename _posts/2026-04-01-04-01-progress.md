1단계: 기본 레이아웃 개선

  - YouTube IFrame API 기반 영상 플레이어
  - 영상 비율 깨지는 문제 수정 (aspect-ratio: 16/9 + position: absolute)
  - 좌우 2단 레이아웃: 영상(62%) / 컨트롤 패널(38%)

  2단계: 워크플로우 설계

  - 어노테이션 기준 논의: 경계 판단 3단계 질문 체계 수립
  - 태그 2종 확정: GAME (게임 이벤트만) / BOTH (게임 + 오디오 변화)
  - "전체 시청 먼저" 단계 제거 → 바로 마킹 시작
  - 로딩 화면 경계 포함 여부 논의 → 포함 결정

  3단계: UX 개선

  - 퀵스타트 가이드 모달 추가 (스크롤 끝까지 읽어야 시작 버튼 활성화)
  - 어노테이터 ID 기반 시드 셔플 → 동일 ID면 항상 같은 순서 재현
  - 타임스탬프 정밀도: 초 단위 → 밀리초 단위

  4단계: 백엔드 연동 (Google Sheets)

  - 로컬 JSON 업로드 방식 → Google Apps Script + Sheets 실시간 저장
  - segments 시트: 영상 목록 관리
  - annotations 시트: 어노테이션 실시간 저장/삭제
  - 세션 재개 기능: 재접속 시 기존 어노테이션 복원, 미완료 영상부터 시작

  5단계: 보안

  - Apps Script URL 노출 문제 → 토큰 인증 방식 채택
  - doGet / doPost 모두 SECRET_TOKEN 검증
  - %%WEBAPP_URL%% / %%SECRET_TOKEN%% 플레이스홀더 방식

  6단계: 트롤링 방지

  - device_id: localStorage에 UUID 저장 → 브라우저 고유 식별
  - device_fp: 언어/플랫폼/해상도 등 환경 해시 → ID 바꿔도 동일 기기 감지
  - 어노테이션 저장 시 두 값을 Sheets에 함께 기록

  7단계: 배포

  - GitHub 레포 → GitHub Actions로 CI/CD 구성
  - 빌드 시 sed로 플레이스홀더 치환 (Secrets 주입)
  - gh-pages 브랜치로 자동 배포
  - 최종 URL:
  https://dltnghks.github.io/annotation-tool/annotation_tool_yt.html



## Annotation Tool 최종 정리

  구성 요소

| 구성 | 내용 |
| --- | --- |
| 프론트엔드 | `annotation_tool_yt.html` (GitHub Pages 배포) |
| 백엔드 | Google Apps Script (Web App) |
| 데이터 저장 | Google Sheets (`segments`, `annotations` 시트) |
| 배포 | GitHub Actions -> `gh-pages` 브랜치 자동 배포 |

  
  주요 기능

  영상 재생
  - YouTube IFrame API, 16:9 비율 고정
  - 좌우 2단 레이아웃 (영상 62% / 컨트롤 38%)
  - 배속 조절(R), 2초 이동(←→), Space 재생/정지

  어노테이션
  - M 키로 경계 표시 → 태그 선택 (1 GAME / 2 BOTH)
  - 밀리초 단위 타임스탬프 기록
  - 타임스탬프 클릭으로 해당 시점 이동, ×로 삭제

  세션 관리
  - Annotator ID 기반 세드 셔플 (동일 ID → 항상 같은 순서)
  - 재접속 시 기존 어노테이션 자동 복원
  - 미완료 영상부터 자동 시작

  데이터 저장
  - 실시간 Google Sheets 저장/삭제
  - video_id, timestamp_ms, tag, annotator_id, saved_at, device_id,
  device_fp 컬럼

  보안 / 트롤링 방지
  - 토큰 인증 (GitHub Secrets → 빌드 시 주입)
  - device_id (localStorage UUID) + device_fp (브라우저 환경 해시) 기록

  가이드
  - 시작 전 필독 모달 (끝까지 스크롤해야 시작 버튼 활성화)
  - 경계 판단 3단계 질문, 태그 기준, 판단 예시 포함
