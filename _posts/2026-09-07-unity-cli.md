`unity upgrade`로 버전 업데이틑 가능


```
unity auth login
unity license activate
```
Unity CLI 원활한 사용을 위해 로그인 실행 및 라이선스를 부여하기

```
unity editors
unity install lts -m platform
```
유니티 버전 확인하고 설치까지 가능

Unity CLI는 기존 MCP 서버를 대체하는 거임

```
unity mcp configure agent
```
configure 명령어를 통해 지원하는 MCP 목록을 확인하고 알맞은 이름을 골라서 구성 파일을 생성한다.
