깃허브
[dltnghks/Bridge-Alien-Analytics](https://github.com/dltnghks/Bridge-Alien-Analytics)

유저의 플레이 패턴, 이벤트 로그 등의 통계를 실시간으로 확인하기 위해서 통계 백엔드를 구현하고자 한다.

```
BridgeAlien.Analytics.Api/
  Controllers/
    AnalyticsController.cs      ← POST /analytics/events
  Models/
    AnalyticsEventDto.cs        ← 이벤트 요청 구조
  Repositories/
    AnalyticsRepository.cs      ← Dapper로 DB 저장
  sql/
    migration.sql               ← players, analytics_events 테이블 생성 SQL
  Program.cs                    ← Swagger UI 포함
  appsettings.json              ← 연결 문자열 자리 비워둠
```


|이벤트|발생 시점|payload 필드|
|---|---|---|
|`session_start`|앱 최초 실행|없음|
|`session_end`|앱 종료/백그라운드|`duration_sec`|
|`stage_enter`|피로도 통과 후 스테이지 진입|없음 (`stage_id` 포함)|
|`stage_clear`|미니게임 종료, star > 0|`score`, `star_count`, `duration_sec`|
|`stage_fail`|미니게임 종료, star == 0|`score`, `duration_sec`|
|`minigame_result`|미니게임 종료 항상|`minigame_type`, `score`, `duration_sec`, `success`, `combo_count`|
