### 기술 스택 & 인프라 (Tech Stack)

- **Core Framework**: Next.js 16.2 (App Router) + React 19 + vinext + Vite 8
- **Styling**: Tailwind CSS v4 (`@tailwindcss/postcss`) + Custom CSS (app/globals.css)
- **Data Management**: Drizzle ORM + Drizzle Kit (db/schema.ts)
- **CI/CD & Deployment**: GitHub Actions (.github/workflows/deploy-pages.yml) - GitHub Pages 자동 배포 (Jekyll 블로그 + `/game/` 라우트 서브 앱 통합)
