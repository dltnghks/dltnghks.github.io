퍼즐 팝업들은 불투명한 백그라운드 Dim이 필요없다.

퍼즐 UI에 사용할 구조를 먼저 작성한다.

```
Canvas
└─ PopupRoot
   └─ PuzzlePopup
      └─ PuzzleFrame
         ├─ PuzzleBorder
         ├─ Header
         │  ├─ TitleText
         │  └─ CloseButton
         └─ Body
            ├─ ContentRoot
            │  └─ PuzzleContent
            └─ PuzzleInventoryIndex   // 필요한 퍼즐만 사용
               ├─ Background
               └─ ItemsRoot
                  └─ InventoryItem
```

1. PuzzlePopupFrame은 공통적으로 들어가는 Prefab으로 디자인
2. PuzzleContent에 들어가는 퍼즐들을 개별적으로 디자인
