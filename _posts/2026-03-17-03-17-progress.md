## 모델
EfficientGEBD, DDM-Net model 사용
**DDM-Net** (2022)
- paper [[2112.04771] Progressive Attention on Multi-Level Dense Difference Maps for Generic Event Boundary Detection](https://arxiv.org/abs/2112.04771)
- model [MCG-NJU/DDM: [CVPR 2022] Progressive Attention on Multi-Level Dense Difference Maps for Generic Event Boundary Detection](https://github.com/MCG-NJU/DDM
- checkpoint [checkpoint.pth.tar - Google Drive](https://drive.google.com/file/d/1k66v9VuFgah3Wx6eKmWpj8_b5MXxlwt7/view)

**EfficientGEBD**(2024)
- paper [[2407.12622] Rethinking the Architecture Design for Efficient Generic Event Boundary Detection](https://arxiv.org/abs/2407.12622)
- model [Ziwei-Zheng/EfficientGEBD: Official implementation of "Rethinking the Architecture Design for Efficient Generic Event Boundary Detection".](https://github.com/Ziwei-Zheng/EfficientGEBD)
- checkpoint [output.zip - Google Drive](https://drive.google.com/file/d/1S4M-xnKpjWFGBimcRYzlEDFhDsWQWF_-/view)

논문에서는 Kinetics-GEBD 데이터셋을 사용
