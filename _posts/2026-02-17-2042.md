[2042번: 구간 합 구하기](https://www.acmic.net/problem/2042)

## 어떤 걸 사용하나요?
이 문제는 **세그먼트 트리(Segment Tree)** 자료구조를 활용하여 해결합니다. 세그먼트 트리는 특정 구간에 대한 질의(예: 구간 합, 최솟값, 최댓값)와 특정 원소 값의 갱신을 효율적으로 처리하기 위한 자료구조입니다.

*   **장점**: 구간 합 질의와 값 갱신 모두 O(log N)의 시간 복잡도로 수행 가능합니다.
*   **`long long` 사용**: 입력 값의 범위가 크고 N 또한 1,000,000으로 크기 때문에, 구간 합의 결과가 `int`형의 표현 범위를 넘어설 수 있습니다. 이를 방지하기 위해 `long long` 타입을 사용하여 오버플로우를 방지합니다.

## 어떻게 구현하나요?
세그먼트 트리는 1차원 배열로 구현되며, 트리의 각 노드는 원본 배열의 특정 구간에 대한 정보를 저장합니다.

1.  **자료구조**:
    *   `numbers`: 원본 배열의 값들을 저장합니다. (long long 타입)
    *   `tree`: 세그먼트 트리를 나타내는 1차원 배열입니다. 원본 배열 크기 `N`에 대해 보통 `4 * N` 크기로 선언합니다. (long long 타입)

2.  **`MakeTree(cur, left, right)` 함수**:
    *   트리를 재귀적으로 구축하는 함수입니다. `cur`은 현재 노드의 배열 인덱스, `left`와 `right`는 현재 노드가 담당하는 원본 배열의 구간을 나타냅니다.
    *   **기저 조건**: `left == right` (리프 노드)인 경우, `tree[cur]`에 `numbers[left]` 값을 직접 저장합니다.
    *   **재귀 호출**: `mid = (left + right) / 2`를 기준으로 왼쪽 자식(`cur * 2`)과 오른쪽 자식(`cur * 2 + 1`)에 대해 `MakeTree`를 재귀 호출합니다.
    *   **값 저장**: 현재 노드 `tree[cur]`에는 왼쪽 자식과 오른쪽 자식 노드의 합을 저장합니다.

3.  **`Change(cur, left, right, target, diff)` 함수**:
    *   `target` 인덱스의 원본 배열 값을 `diff`만큼 변경하고, 이 변화를 세그먼트 트리에 반영하는 함수입니다.
    *   `diff`는 변경 전 값과 변경 후 값의 차이입니다.
    *   **경로 탐색**: `target` 인덱스가 현재 노드의 담당 구간(`left` ~ `right`) 안에 있을 경우, `tree[cur]`에 `diff`를 더하여 값을 갱신합니다.
    *   **재귀 호출**: 현재 노드가 리프 노드가 아니라면, `target` 인덱스가 포함된 자식 노드(`cur * 2` 또는 `cur * 2 + 1`)에 대해 `Change` 함수를 재귀 호출하여 변경 사항을 전파합니다.
    *   `numbers[target]` 값도 새로운 값으로 업데이트해야 합니다. (코드에서는 `numbers[b] = c;` 부분)

4.  **`Solve(cur, left, right, targetL, targetR)` 함수**:
    *   `targetL`부터 `targetR`까지의 구간 합을 질의하는 함수입니다.
    *   **완전 포함**: 현재 노드의 담당 구간(`left` ~ `right`)이 질의 구간(`targetL` ~ `targetR`)에 완전히 포함되면, `tree[cur]` 값을 즉시 반환합니다.
    *   **완전 벗어남**: 현재 노드의 담당 구간이 질의 구간과 완전히 겹치지 않으면 `0`을 반환합니다.
    *   **부분 포함**: 현재 노드의 담당 구간이 질의 구간과 부분적으로 겹치면, 왼쪽 자식과 오른쪽 자식에 대해 재귀 호출하여 얻은 결과들을 합산하여 반환합니다.


---

### 1. 자료형 (Overflow 주의)

가장 흔하게 하는 실수입니다.

- **문제:** 데이터의 개수($N$)가 $1,000,000$이고 값의 범위가 크면, 구간 합은 `int` 범위를 가볍게 넘깁니다.
    
- **인지할 점:** `numbers` 배열, `tree` 배열, 그리고 합을 반환하는 모든 함수의 리턴 타입은 반드시 **`long long`**이어야 합니다. `int`로 선언하는 순간 "왜 틀렸지?"라며 멘붕에 빠지기 쉽습니다.
    

### 2. Update(Change) 시점과 방식

이번 코드에서 가장 헤맸던 부분이죠.

- **인지할 점:** * **차이값(`diff`) 방식:** `numbers[b]`를 **갱신하기 전**에 `diff = 새로운값 - 기존값`을 구해야 합니다.
    
    - **직접 갱신 방식:** 리프 노드까지 내려가서 값을 바꾸고, 올라오면서 부모 노드들을 다시 계산(`tree[cur] = tree[L] + tree[R]`)하는 방식도 있습니다. (이 방식이 실수가 적어 실전에서 추천됩니다.)
        

### 3. 트리 배열의 크기 (4N의 법칙)

- **문제:** 트리를 저장할 배열 크기를 `n`으로 잡으면 인덱스 초과 에러(Out of bounds)가 납니다.
    
- **인지할 점:** 세그먼트 트리는 이진 트리 구조이므로 메모리를 넉넉하게 써야 합니다. 안전하게 **`4 * n`** 크기로 선언하세요.
    

### 4. 재귀의 기저 사례(Base Case)와 저장

- **인지할 점:** `MakeTree`나 `Update` 함수를 짤 때, 값을 계산만 하고 **`tree[cur]`에 저장**하지 않으면 트리는 계속 빈 상태로 남습니다.
    
    - **나쁜 예:** `return MakeTree(...) + MakeTree(...)`
        
    - **좋은 예:** `return tree[cur] = MakeTree(...) + MakeTree(...)`

### 💡 주의사항

> **"입력값과 리턴값은 `long long`인가? 배열 크기는 `4N`인가? `Update` 시 `diff` 계산은 갱신 전인가?"**

이 세 가지만 머릿속에 넣고 코딩을 시작해도 디버깅 시간이 80%는 줄어듭니다.

다음에 풀 때는 `diff` 방식 대신, 리프 노드를 찍고 올라오면서 부모 노드를 갱신하는 **`update(cur, left, right, target, val)`** 방식을 한 번 시도해 보시겠어요? 이 방식이 나중에 '최솟값/최댓값 구하기' 등으로 응용하기 훨씬 편하거든요! 관련해서 궁금하시면 구현법을 알려드릴게요.

```c++
#include <iostream>
#include <vector>
using namespace std;

int n, m, k;
vector<long long> numbers;
vector<long long> tree;

long long MakeTree(int cur, int left, int right){

    if(left > right){
        return 0;
    }
    if(left == right){
        tree[cur] = numbers[left];
        return numbers[left];
    }

    int mid = (left + right) / 2;
    int childL = cur * 2;
    int childR = cur * 2 + 1; 
    return tree[cur] = MakeTree(childL, left, mid) + MakeTree(childR, mid+1, right);    
}

void Change(int cur, int left, int right, int target, long long diff){

    if(left > target || target > right){
        return;
    }

    int mid = (left + right) / 2;
    int childL = cur * 2;
    int childR = cur * 2 + 1;
    tree[cur] += diff;
        
    if(left != right){
        Change(childL, left, mid, target, diff);
        Change(childR, mid+1, right, target, diff);
    }
}

long long Solve(int cur, int left, int right, int targetL, int targetR){
    // 범위 안에 들어오면 그 값을 리턴
    if(targetL <= left && right <= targetR){
        return tree[cur];
    }
    // 완전 범위를 벗어나면 0
    else if(targetL > right || left > targetR){
        return 0;
    }

    long long sum = 0;
    int mid = (left + right) / 2;
    int childL = cur * 2;
    int childR = cur * 2 + 1;    
    sum = Solve(childL, left, mid, targetL, targetR) + Solve(childR, mid+1, right, targetL, targetR);

    return sum;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    cin >> n >> m >> k;

    numbers = vector<long long>(n+1);
    tree = vector<long long>(4 * n + 1);

    // 초기 숫자.
    for(int i = 1; i <= n; i++){
        cin >> numbers[i];
    }

    MakeTree(1, 1, n);

    // 숫자 변경
    for(int i = 0; i < m+k; i++){
        int a, b;
        long long c;
        cin >> a >> b >> c;
        // a가 1인 경우 변경(b번째 숫자를 c로)
        if(a == 1){
            long long diff = c - numbers[b];
            numbers[b] = c;
            Change(1, 1, n, b, diff);
        }
        // a가 2인 경우 구간 합(b~c) 구하기
        else if(a == 2){
            cout << Solve(1, 1, n, b, c) << '\n';
        }

    }

    return 0;
}
```
