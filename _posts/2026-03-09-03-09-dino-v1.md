“DINO가 ViT 기반 self-supervised learning에서 왜 잘 동작하는지 설명하기”

## CNN /ResNet /Vit
- `CNN`은 이미젱 맞게 설계된 전통적인 비전 모델
- `ResNet`은 CNN을 깊게 쌓을 수 있게 만든 대표 구조
- `ViT`는 이미지를 patch로 나눠 Transformer로 처리

### CNN
`CNN`은 이미지의 가까운 픽셀 패턴을 잡는 데 강하다.
처음 층에서는 선, 모서리, 간단한 질감을 보고, 깊어질수록 눈, 얼굴, 물체 형태 같은 더 큰 특징을 보게 된다.
핵심 연산은 `convolution`이고, 작은 필터를 이미지 위로 움직이면서 특징을 뽑아낸다.

### ResNet
ResNet은 CNN의 한 종류이고, 중요한 아이디어는 `skip connection`이다.
보통 깊은 네트워크 층이 많아질수록 학습이 어려워진다.
ResNet은 입력을 다음 블록으로 그냥 더해 줘서, 모델이 "완전히 새로 만들기"보다 "원래 값에서 조금 수정하기"를 배우게 한다.
이 구조 덕분에 ResNet-50, ResNet-101, ResNet-200처럼 깊은 모델이 잘 학습된다.
- ResNet-50 = 50층짜리 ResNet
- RN50w2 = ResNet-50인데 width(채널 수)를 2배로 늘린 것
- RN50w4 = ResNet-50인데 width를 4배로 늘린 것
- RN200w2 = ResNet-200이고 width도 2배 늘린 것
즉:
- 50, 200 = depth, 레이어 수
- w2, w4 = width, 채널 수(feature dimension)

### ViT
`Vision Transformer`이고, CNN처럼 필터를 훑는 대신 이미지를 patch 조각들로 나눈다.
```
[patch1] [patch2] [patch3]
[patch4] [patch5] [patch6]
```
이미지를 이런 형식으로 잘라서 patch들을 token처럼 보고 Transformer에 넣는다.
즉, ViT는 이미지를 단어처럼 잘라서 처리하는 방식" 이라고 생각하면 된다.

### CNN과 ViT의 차이점
`CNN`은 local pattern부터 점점 넓혀간다.
`ViT`는 patch들을 token처럼 보고 관계를 attention으로 학습한다.

|항목|CNN / ResNet|ViT|
|---|---|---|
|입력 처리|필터로 이미지 훑기|patch로 나눠 token처럼 처리|
|핵심 연산|convolution|self-attention|
|잘하는 방식|local 패턴부터 학습|patch 간 관계를 전역적으로 학습|
|대표 모델|ResNet-50|ViT-B/16|

## Transformer / Attention
- self-attention?
- multi-head attention?
- Transformer가 토큰 표현을 어떻게 바꾸는지?

### self-attention
Transformer는 입력 token들 사이의 관계를 attention으로 학습하는 구조다.
텍스트에서는 token이 단어, ViT에서는 token이 patch다.
즉 입력 종류만 다르고 구조의 본질은 같다.

"철수가 학교에 가서 책을 읽었다."
여기서 `읽었다`를 이해하려면:
- 누가 읽었는지(`철수`)
- 무엇과 관련 있는지(`책`)
와 같은 다른 단어들을 참고해야 한다.

Transformer는 이런 관계를 자동으로 본다.
이게 `self-attention`이다.
즉, 각 `token`이 다른 모든 `token`을 참고해서 자기 표현을 업데이트하는 것.

조금 더 정확하게 말하면
- 입력 token마다 현재 표현 벡터가 있음.
- attention이 "누구를 얼마나 참고할지"를 계산
- 그 결과로 각 token의 표현이 문맥에 맞게 바뀜

그래서 Transformer는 단순히 단어 하나를 보는 게 아니라, 문맥이 반영된 token representation을 만든다.

### multi-head attention
한 개의 attention만 쓰면 관계를 하나의 방식으로만 볼 수 있다.
그래서 Transformer는 attention을 여러 개 병렬로 둔다.

- 입력은 같음
- 각 head는 다른 가중치를 가짐
- 그래서 같은 입력도 다른 관점으로 봄
```
같은 입력
 ├─ Head 1: 가까운 관계에 주목
 ├─ Head 2: 긴 거리 관계에 주목
 ├─ Head 3: 의미적 관계에 주목
 └─ Head 4: 구조적 관계에 주목
```
- head마다 입력이 다른게 아님.
- **입력은 같고**
- `W_Q`, `W_K`, `W_V` 같은 가중치가 다름.
- 그래서 서로 다른 attention map이 생긴다.

### attentino 처리 과정
"고양이 잔다."
```
Token 1 = "고양이"
Token 2 = "잔다"
```

token의 현재 표현 벡터
```
x1 = [1, 0]
x2 = [0, 1]
```

이거를 `Q,K,V`로 바꾼다.
설명을 위해 가중치 행렬은 단순하게 설정
```
W_Q = [[1, 0],
       [0, 1]]

W_K = [[1, 1],
       [0, 1]]

W_V = [[1, 0],
       [2, 1]]
```

그러면 각 token의 Q,K,V는
```
q1 = x1 W_Q = [1, 0]
q2 = x2 W_Q = [0, 1]

k1 = x1 W_K = [1, 1]
k2 = x2 W_K = [0, 1]

v1 = x1 W_V = [1, 0]
v2 = x2 W_V = [2, 1]
```

`Token 1`이 다른 token들을 얼마나 참고할지 계산해보자.
`Token 1`의 query는 `q1 = [1, 0]`이다.
이거를 각 key와 내적
```
q1 · k1 = [1,0] · [1,1] = 1
q1 · k2 = [1,0] · [0,1] = 0
=> [1, 0]
=> softmax([1, 0]) = [0.73, 0.27]
```

`Token 1`은 자기 자신을 73%
`Token 2`를 27% 정도로 참고한다.

그 다음 이 가중치로 value를 섞는다.
```
output1 = 0.73 * v1 + 0.27 * v2
        = 0.73 * [1,0] + 0.27 * [2,1]
        = [0.73,0] + [0.54,0.27]
        = [1.27, 0.27]
```
이게 `Token 1`의 표현

## DINO 구조

### DINO
DINO는 vision encdoer 자체가 아니라 ViT나 ResNet같은 vision encoder를 self-supervised하게 학습시키는 방법

- ViT-S/16, ViT-B/8 같은 게 encoder
- DINO는 그 encoder를 학습하는 방식

![Pasted image 20260309161802](/assets/img/posts/2026-03-09-03-09-dino-v1/pasted-image-20260309161802-006f4824.png)
전체 구조는 student-teacher self-distillation 구조다.
- teacher output을 target처럼 사용
- student output이 teacher와 비슷해지도록 학습

즉 핵심 목표는
`student가 teacher의 출력을 맞추도록 한다.`

### Student와 Teacher
둘의 구조는 동일하다.
하지만 역할이 다르다.
`Student`
- 실제로 optimizer로 학습되는 네트워크
- global crop과 local crop을 모두 입력 받음
- gradient descent로 업데이트 됨.

`Teacher`
- student가 따라야 할 target을 만드는 네트워크
- global crop만 입력받음.
- gradient로 업데이트되지 않음.
- student의 EMA(Exponential Moving Average)로 업데이트됨.

### Global crop / Local crop
여기서 `global crop`은 원본 이미지 전체 그대로가 아니다.
원본에서 **큰 영역을 랜덤하게 자른 뷰.**
- `global crop` = 큰 범위의 이미지 뷰
- `local crop` = 작은 일부만 자른 뷰

DINO의 포인트
- student는 `global + local` 둘 다 본다.
- teacher는 `global`만 본다.
이 의미는 student가 작은 부분을 보고도 teacher가 큰 문맥으로 만든 표현과 일치하도록 학습하도록 하는 것이다.
논문에서는 `local-to-global correspondence`라고 말한다.

### EMA(Exponential Moving Average)
Teacher는 backprop으로 배우지 않는다.
즉 teacher는 student의 파라미터를 천천히 평균낸 버전
```
teacher = m * teacher + (1 - m) * student
```
여기서 m은 보통 1에 가까운 값.
의미
- teacher는 갑자기 확 바뀌지 않음.
- student보다 더 부드럽고 안정적인 모델이 된다.

그래서 teacher는 흔들리는 student를 바로 복사한 것이 아니라 천천히 따라오는 `안정적인 기준 모델 역할`을 한다.

### Centering / Sharpening
DINO는 그냥 teacher를 따라하기만 하면 안된다.
그렇게 하면 모델이 전부 비슷한 값만 내는 방향으로 무너질 수 있다.
=> `Collapse`

`Centering`
- teacher 출력의 평균적인 편향을 빼 줌.
- 한 차원이나 일부 Prototype에 계속 쏠리는 걸 줄임.


`Sharpening`
- teacher 출력 분포를 더 뾰족하게 만듦.
- 애매한 확률분포 대신 더 명확한 target을 줌.
