## Multiplayer Service
Unity Gameing Services, 즉 UGS를 기반으로 멀티플레이어 기능을 붙이기 위한 SDK다.
핵심 개념은 Session이다.
> **Session**
> 여러 플레이어가 하나의 게임 그룹으로 묶여 함께 플레이하는 단위.
- 플레이어 그룹 생성
- 세션 참가
- 세션 관리
- 멀티플레이어 연결 흐름 구성
- UGS 기반 서비스와 연동

Netcode for GameObjects, Netcode for Entities 둘 다 기본적으로 호환된다.

## Multiplayer Widgets

Multiplayer Services를 더 쉽게 테스트하기 위한 UI 위젯 패키지다.

직접 로그인 UI, 세션 생성 UI, 참가 UI 등을 처음부터 만들기 전에, Unity가 제공하는 기본 위젯으로 흐름을 빠르게 확인할 수 있다.
- 간단한 멀티플레이어 UI 테스트
- 세션 생성/참가 흐름 실험
- UGS 연동 방식 확인
- 프로토타입 제작

폐지됨? [Unity - Manual: Unity Building Blocks](https://docs.unity3d.com/Manual/building-blocks.html)
Unity Building Blocks을 쓰라고 나와있음.

## Netcode for GameObjects

GameObject 기반 Unity 프로젝트에서 사용하는 고수준 네트워킹 라이브러리다.

Unity의 일반적인 개발 방식인 GameObject, Component, MonoBehaviour 구조와 잘 맞다.
- GameObject 상태를 네트워크로 동기화
- 여러 플레이어에게 월드 데이터 전달
- RPC, NetworkVariable 같은 네트워크 기능 제공
- 대부분의 일반적인 멀티플레이어 게임에 적합
- 클라이언트-서버 구조 지원
- 분산 권한 구조도 지원

다음 게임에 적합하다.
- 협동 게임
- 소규모 PvP
- 캐주얼 멀티플레이어
- 방 기반 게임
- 일반적인 Unity GameObject 프로젝트

다만 매우 큰 규모이거나 성능 최적화가 중요한 게임이라면 Netcode for Entities가 더 적합할 수 있다.

---

## Netcode for Entities

Unity DOTS 기반의 고성능 네트워킹 시스템입니다.

Entities, ECS, Burst, Jobs 같은 데이터 지향 기술과 함께 사용됩니다.

- 대규모 멀티플레이어 게임에 적합
- 높은 성능과 최적화에 유리
- 서버 권한 방식 지원
- 클라이언트 예측 기능 제공
- 고급 개발자에게 적합
- 클라이언트-서버 구조만 지원

다음 게임에 적합하다.
- 대규모 전투 게임
- 많은 유닛이 동시에 움직이는 게임
- 고성능 시뮬레이션
- DOTS 기반 프로젝트
- 서버 권한 구조가 중요한 경쟁 게임

## NetworkBehaviour?
Unity Netcode for GameObjects에서 쓰는 네트워크용 MonoBehaviour


---
현재 코드 구조
Bootstrap -> Lobby -> Game

1. BootstrapLoader는 시작 시 RuntimeNetworkManager에 기본 주소를 설정한다.
	1. 상태 업데이트
2. 키 입력에 따라
	1. 싱글 게임 시작
	2. 방 생성
	3. 방 참여
	4. 종료

---
싱글 플레이 시작 시
RuntimeNetworkManager를 Shutdown한 후 gameplayScene을 로드한다.

게임 플레이 이후 Sync를 맞추기 위한 작업은 아직 진행되지 않았음.
