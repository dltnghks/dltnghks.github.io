# Sound Event Detection and Time-Frequency Segmentation from Weakly Labelled Data

> Kong, Q., Xu, Y., Sobieraj, I., Wang, W., & Plumbley, M. D. (2019).
> **IEEE/ACM Transactions on Audio, Speech, and Language Processing**, 27(4), 777–791.
> arXiv: [1804.04715](https://arxiv.org/abs/1804.04715)

---

## 1. 핵심 요약 (What / How / Why)

| | |
|---|---|
| **What** | Weakly label(클립 단위 존재 여부 태그만 있는 데이터)로 학습해, 사운드 이벤트의 onset/offset 시점과 time-frequency 범위를 동시에 추정한다. |
| **How** | CNN으로 log mel spectrogram → T-F segmentation mask를 생성하고, Global Weighted Rank Pooling(GWRP)으로 클립 단위 예측을 수행하는 두 단계 프레임워크를 구성한다. |
| **Why** | 실제 SED 데이터셋의 대부분은 onset/offset 주석이 없는 weak label만 존재한다. 강한 주석 없이 temporal localization과 T-F 분리를 함께 달성하는 방법이 필요하다. |

---

## 2. 문제 정의

기존 SED 연구는 **strong label**(onset/offset 시간 주석)을 요구한다.
그러나 대규모 실세계 데이터셋(예: AudioSet, DCASE)은 대부분 **weak label** — 클립 안에 해당 이벤트가 존재하는지 여부만 — 을 제공한다.

이 논문은 세 가지 과제를 동시에 해결하는 것을 목표로 한다:

1. **Audio Tagging** – 클립 단위 클래스 분류
2. **Frame-wise / Event-wise SED** – 이벤트의 temporal localization (onset/offset)
3. **T-F Segmentation** – 이벤트가 발생한 time-frequency 영역의 마스크 추정

---

## 3. 방법론

### 3.1 입력 표현

- **Log mel spectrogram**: 오디오 신호를 $T \times F$ 행렬로 변환 ($T$: 시간 프레임, $F$: mel 필터 수)

### 3.2 Segmentation Mapping (CNN)

CNN을 적용해 입력 spectrogram $X \in \mathbb{R}^{T \times F}$에서 각 클래스 $k$에 대한 T-F 마스크 $M_k \in [0,1]^{T \times F}$를 생성한다.

$$M_k = \text{CNN}_k(X)$$

마스크는 이벤트가 발생하는 시간-주파수 영역을 soft하게 표시하며, 이 마스크와 원본 spectrogram의 element-wise product가 해당 이벤트의 분리된 표현이 된다.

### 3.3 Classification Mapping (GWRP)

T-F 마스크에서 클립 단위 확률을 집계하기 위해 **Global Weighted Rank Pooling (GWRP)**을 사용한다.

- 마스크 $M_k$의 각 원소를 내림차순으로 정렬하고, 순위에 따라 감소하는 가중치를 부여한다.
- Global Average Pooling(GAP)보다 상위 활성화에 더 집중할 수 있어, 짧게 발생하는 이벤트 탐지에 유리하다.

$$\hat{y}_k = \sum_{i} w_i \cdot M_k^{(i)}, \quad w_i \propto r^{i-1} \quad (0 < r < 1)$$

여기서 $r$은 rank decay 계수 (하이퍼파라미터).

### 3.4 학습

- **손실 함수**: Binary Cross-Entropy (클립 단위 weak label 사용)
- Temporal 주석 없이 end-to-end 학습 가능
- 추론 시 T-F 마스크에서 임계값을 통해 onset/offset 추출

## 오디오 클립 처리 파이프라인 (상세)

### 1단계: 전처리 → Log Mel Spectrogram

```
오디오 클립 (mono, 32 kHz)
    ↓
STFT (FFT window=2048, hop=1024 → 50% overlap)
    ↓
Mel filterbank 적용 (64 bands)
    ↓
로그 스케일 압축 → Log Mel Spectrogram
    ↓
입력 shape: 1 × 311 × 64  (채널 × 시간프레임 × mel bin)
```

- hop size 1024 기준으로 한 프레임 ≈ 32ms
- 311 프레임 ≈ 약 10초 클립

### 2단계: CNN → T-F Segmentation Mask

**핵심: spatial downsampling이 전혀 없음.** 매 레이어를 거쳐도 T×F 해상도(311×64)가 유지된다.

| 블록 | 구성 | 출력 shape |
|---|---|---|
| Input | — | 1 × 311 × 64 |
| Conv Block 1 | 3×3 conv ×2, 32 filter, BN, ReLU | 32 × 311 × 64 |
| Conv Block 2 | 3×3 conv ×2, 64 filter, BN, ReLU | 64 × 311 × 64 |
| Conv Block 3 | 3×3 conv ×2, 128 filter, BN, ReLU | 128 × 311 × 64 |
| Conv Block 4 | 3×3 conv ×2, 128 filter, BN, ReLU | 128 × 311 × 64 |
| Final | 1×1 conv, 41 filter, sigmoid | **41 × 311 × 64** |

- Batch Normalization은 매 conv 뒤, ReLU 앞에 적용
- 최종 출력: 41개 클래스 각각의 T-F 마스크 (값 범위 [0, 1])

### 3단계: 마스크 → Frame-level 점수

T-F 마스크의 주파수 축을 평균내서 시간축 1D 점수열을 만든다.

$$v_k(t) = \frac{1}{F} \sum_{f=1}^{F} h_k(t, f)$$

이 $v_k(t)$에 임계값을 적용하면 onset/offset을 추출할 수 있다.

### 4단계: GWRP → 클립 단위 확률 (학습용)

프레임 점수를 내림차순으로 정렬한 뒤 rank에 따라 감소하는 가중치로 집계한다.

$$\hat{y}_k = \frac{1}{Z(r)} \sum_{j=1}^{M} r^{j-1} \cdot v_k^{(j)}, \quad Z(r) = \sum_{j=1}^{M} r^{j-1}$$

| $r$ 값 | 동작 |
|---|---|
| $r = 0$ | Global Max Pooling (최대값만 사용) |
| $r = 1$ | Global Average Pooling (균등 가중치) |
| $0 < r < 1$ | 상위 프레임에 더 높은 가중치 부여 |

학습: $\hat{y}_k$와 weak label(클립 태그)로 Binary Cross-Entropy 최소화
학습 설정: Adam, lr=0.001, batch size=24, 4-fold cross-validation

### 전체 흐름 요약

```
클립 → Log Mel Spec (1×311×64)
              ↓ CNN (no downsampling)
       T-F Mask (41×311×64)
              ↓ freq 평균
      Frame score (41×311)
         ↙              ↘
    임계값 적용           GWRP
  onset/offset 추출   클립 예측 → 학습 loss
```

## 2019년 이후 발전 흐름

### 2019–2020: CRNN + Semi-supervised 등장

**PANNs** (Kong et al., 2020)
- AudioSet 200만 클립으로 CNN14 등 대규모 사전학습 모델 공개
- 이후 모든 SED 연구의 인코더로 사용 (vision의 ImageNet pretrain과 동일한 역할)

**DCASE Task 4 + Mean Teacher** (Turpault et al., 2019/2020)
- CRNN (CNN + BiGRU) + Attention pooling 구조가 표준 baseline으로 정착
- **Mean Teacher** 도입: 학생 모델은 역전파로 학습, 교사 모델은 학생의 EMA로 업데이트 → unlabeled 데이터에 pseudo-label 부여
- 2020년 이후 DCASE Task 4의 지배적 학습 패러다임이 됨

> Kong 2019의 GWRP → softmax attention pooling으로 교체되기 시작. 학습 가능한 pooling이 GWRP보다 낫다는 게 실증됨

---

### 2021–2022: Transformer 아키텍처 침투

**AST** (Gong et al., Interspeech 2021)
- 순수 ViT를 spectrogram에 적용, ImageNet pretrained 가중치로 초기화
- AudioSet mAP 0.459 달성 → Transformer가 오디오에서도 통한다는 걸 증명

**PaSST** (Koutini et al., 2022)
- Patchout(학습 중 spectrogram 패치 랜덤 드롭)으로 Transformer를 효율적으로 학습
- AudioSet mAP 0.471, 이후 SED 시스템의 인코더로 널리 채택

DCASE 2022 기준 Transformer 인코더 + RNN 디코더 조합이 표준화, PSDS1 ~0.50–0.57 달성

---

### 2022–2023: Foundation Model 인코더 시대

**BEATs** (Chen et al., Microsoft, ICML 2023)
- 토크나이저와 Transformer를 반복적으로 공동 학습 (masked token prediction)
- AudioSet mAP 0.486, 이후 DCASE 최상위권 시스템이 전부 BEATs 인코더 사용

**ATST-SED** (NTU/USTC, 2023)
- 자기지도 Transformer(ATST)를 frame-level SED로 fine-tuning
- DCASE 2023 PSDS1: 0.649

DCASE 2023 기준 PSDS1 0.62–0.67 달성. GWRP는 완전히 사라짐 → frame-level cross-attention이 표준

---

### 2024–2025: 구체 논문

**ATST-SED** (Shao et al., ICASSP 2024, [arXiv:2309.08153](https://arxiv.org/abs/2309.08153))
- 자기지도 Audio Teacher-Student Transformer(ATST)를 frame-level SED에 맞게 fine-tuning
- 2단계 학습: (1) CRNN 헤드만 학습(인코더 동결) → (2) 전체 joint fine-tuning
- PSDS1: 0.587 — 이후 DCASE 2024 우승팀 접근법의 직접적 원형

**MAT-SED** (Cai et al., Interspeech 2024, [arXiv:2408.08673](https://arxiv.org/abs/2408.08673))
- CRNN에서 RNN을 완전히 제거하고 Relative Positional Encoding을 가진 순수 Transformer로 교체
- 도메인 내 unlabeled 데이터로 masked-reconstruction 자기지도 사전학습
- PSDS1: 0.587

**Sound Event Bounding Boxes (SEBB)** (Ebbers et al., Interspeech 2024, [arXiv:2406.04212](https://arxiv.org/abs/2406.04212))
- 이벤트를 (클래스, 시간 범위, 신뢰도) 튜플로 표현하는 새로운 예측 포맷 제안
- 기존 frame-level 출력에 재학습 없이 적용 가능한 변환 알고리즘 제공
- 기존 DCASE 2023 시스템에 후처리로 적용 시 PSDS1: 0.644 → **0.686**

**DCASE 2024 Task 4 우승** (Schmid et al., CPJKU, [arXiv:2407.12997](https://arxiv.org/abs/2407.12997))
- 3개 사전학습 Transformer(PaSST, BEATs, ATST) 앙상블 → pseudo-label 생성 → 2-stage 반복 학습
- 이종 데이터셋(DESED + MAESTRO Real) 동시 학습, 레이블 누락 처리
- PSDS1: **0.692** (단일 모델 기준 SOTA)

**PMAM** (Cai et al., 2024, [arXiv:2409.17656](https://arxiv.org/abs/2409.17656))
- GMM 기반 프로토타입으로 unlabeled 프레임에 의미론적 pseudo-label 생성
- 동시 발생 이벤트를 BCE로 처리하는 masked audio model 사전학습
- PSDS1: 0.625

**JiTTER** (Nam & Park, 2025, [arXiv:2502.20857](https://arxiv.org/abs/2502.20857))
- 마스크 예측 대신 **시간 순서 셔플 복원**을 자기지도 목표로 사용
- onset/offset 탐지에 명시적 시간 추론 능력이 더 유리함을 주장
- MAT-SED 대비 PSDS1 +5.89%

**Boundary-Aware SED** (Schmid et al., 2026, [arXiv:2601.04178](https://arxiv.org/abs/2601.04178))
- 프레임 단위 출력을 후처리하는 대신, 네트워크 내에 onset/offset 경계를 직접 모델링하는 RED(Recurrent Event Detection) + EPN(Event Proposal Network) 레이어 도입
- AudioSet Strong 전 클래스에서 새로운 SOTA 달성

# Audio-based Generic Event Boundary Detection for Game Video

> 게임 비디오에서 시각적 노이즈(플래시, HUD)로 인해 비주얼 기반 GEBD가 실패하는 문제를,  
> 오디오 신호 기반 taxonomy-free 이벤트 경계 감지로 해결한다.

---

## 1. 연구 배경 및 동기

### 1.1 게임 비디오 Event Boundary Detection의 필요성

게임 비디오는 스트리밍 플랫폼(Twitch, YouTube Gaming 등)에서 방대한 양이 생산되고 있다. 게임 비디오를 의미 있는 단위로 자동 분할하는 EBD는 하이라이트 추출, 자동 클립 생성, 게임 이해(game understanding) 등 다양한 downstream task의 기반이 된다.

### 1.2 기존 Video GEBD의 한계

기존 GEBD 연구(Shou et al., ICCV 2021; Online GEBD, ESTimator)는 일반 영상을 대상으로 설계되어, 게임 비디오의 특수한 시각적 특성으로 인해 다음과 같은 문제가 발생한다.

|문제|설명|기존 GEBD에 미치는 영향|
|---|---|---|
|플래시 / 빠른 화면 전환|총격·스킬·폭발 이펙트로 인한 급격한 시각 변화|이벤트 _내부_의 노이즈가 경계로 오감지 → False Positive 급증|
|HUD / UI|체력바, 탄약, 미니맵 등이 매 프레임 변화|Kinetics 사전학습 모델은 HUD 미학습 → 이벤트 신호와 UI 신호 혼동|

### 1.3 오디오 기반 접근의 근거

게임 이벤트와 사운드는 거의 1:1로 대응한다. 총격, 발소리, 스킬 사용, 아이템 획득 등 모든 이벤트는 고유한 사운드 이펙트를 동반하며, 이 소리들은 onset이 밀리초 단위로 sharp하여 경계 신호로서 우수하다.

- **HUD 문제 없음**: 사운드에는 UI 요소가 존재하지 않음
- **플래시는 사운드로 정확한 onset**: 시각적 노이즈가 오디오 관점에서는 명확한 이벤트 신호
- **장르 무관 일반화**: 게임 장르와 관계없이 이벤트-사운드 대응 관계는 보편적

---

## 2. 연구 목표

- **주 목표**: 게임 비디오의 오디오 스트림만을 입력으로 하여, 사전 정의된 클래스 없이 (taxonomy-free) 이벤트 경계를 실시간으로 감지하는 모델 제안
- **부 목표**:
    - 게임 비디오 EBD 벤치마크 데이터셋 구축
    - 비주얼 GEBD 대비 오디오 GEBD의 우월성 실험적 증명
    - 다양한 게임 장르에 대한 일반화 능력 검증

---

## 3. 제안 방법: Audio Online-GEBD

Online GEBD의 Event Segmentation Theory(EST) 기반 프레임워크(ESTimator)를 오디오 도메인에 적용하여 설계한다.

### 3.1 전체 파이프라인

```
게임 오디오 스트림
    ↓ (16kHz 리샘플링 → Log Mel Spectrogram)
[BEATs Feature Extractor]  ← frozen, 장르 일반화를 위해 fine-tuning 없이 사용
    ↓ (프레임별 D차원 임베딩 시퀀스)
[CEA: Consistent Event Anticipator]  ← GRU 기반
    ↓ (예측 오차 시퀀스)
[OBD: Online Boundary Discriminator]  ← 동적 threshold
    ↓
경계 타임스탬프 출력 (taxonomy-free)
```

### 3.2 CEA (Consistent Event Anticipator)

- GRU가 과거 임베딩 시퀀스를 입력받아 **다음 프레임 임베딩을 예측**
- 이벤트가 안정적으로 진행 중일 때 → 예측 오차 낮음
- 이벤트 경계(onset) 순간 → 예측 오차 급증
- **EST Loss**: 경계 프레임에서 오차 최대화, 이벤트 내부에서 최소화
- **REST Loss**: 경계 주변의 부드러운 전환을 위한 region 단위 supervision

### 3.3 OBD (Online Boundary Discriminator)

- 과거 예측 오차를 고정 크기 큐(queue)에 저장
- 통계적 검정(statistical test)으로 현재 오차가 이상치인지 판단
- **동적 threshold**: 게임별, 장면별 오차 분포 차이에 자동 적응
- threshold 하이퍼파라미터 튜닝 불필요 → 장르 일반화에 유리

### 3.4 BEATs를 frozen으로 쓰는 이유

BEATs는 AudioSet-2M으로 사전학습된 모델로, 다양한 오디오 이벤트의 고수준 의미 표현을 이미 학습했다. 특정 게임 데이터로 fine-tuning하면 해당 게임에 과적합될 위험이 있으므로, frozen 상태로 사용하여 **장르 무관 일반화**를 확보한다.

---

## 4. 데이터셋 구축

### 4.1 필요성

현재 게임 비디오 EBD를 위한 공개 벤치마크 데이터셋이 존재하지 않는다. 데이터셋 구축 자체가 본 연구의 contribution 중 하나이다.

### 4.2 Annotation Guideline

GEBD 원 논문의 방식을 참고하되, 게임 도메인에 맞게 경계 유형을 정의한다. 단, **모델 출력은 taxonomy-free**이며, 아래 분류는 annotation 일관성을 위한 가이드라인으로만 사용한다.

|경계 유형|예시|
|---|---|
|전투 시작 / 종료|교전 개시, 전투 종료 후 정적|
|상태 변화|사망, 부활, 체력 급감|
|아이템 / 오브젝트 상호작용|아이템 획득, 문 열기, 탈것 탑승|
|환경 전환|실내 ↔ 실외, 구역 이동|
|스킬 / 능력 사용|특수 스킬 발동|

### 4.3 수집 전략

- **학습 데이터**: Scaper를 활용한 합성 데이터 → onset/offset 자동 레이블 생성
    - Foreground: BattleSound, BGG 등 기존 게임 사운드 데이터셋의 개별 이펙트 파일
    - Background: 게임 배경음(BGM, 환경음)
- **평가 데이터**: 실제 게임 플레이 영상에서 수동 레이블링 → 도메인 갭 직접 측정
- **다양성 확보**: FPS, MOBA, RPG 등 최소 3개 이상 장르에서 수집

### 4.4 Annotation 검증

다수 annotator가 동일 영상에 독립 레이블링 → 일치도(annotator agreement) 측정. GEBD 원 논문과 동일하게 consistency score를 함께 제공한다.

## 5. 실험 계획

### 5.1 실험 1 — Motivation 검증 (비주얼 GEBD 실패 분석)

- 기존 Video GEBD 모델(ESTimator, DDM 등)을 게임 비디오에 적용
- 플래시·HUD로 인한 False Positive 케이스를 정량화
- **목적**: "왜 비주얼이 안 되는가"를 수치로 제시 → 연구 동기 강화

### 5.2 실험 2 — 제안 방법 성능 비교

|Baseline|설명|
|---|---|
|Video GEBD (ESTimator)|비주얼 기반 온라인 GEBD|
|Audio Offline GEBD|미래 오디오 사용 허용 (상한선)|
|BEATs + CRNN + threshold|기존 SED 방식으로 경계 추정|
|RED + EPN (Schmid 2026)|최신 Boundary-Aware SED|
|**제안: Audio Online-GEBD**|본 논문 방법|

### 5.3 실험 3 — 장르 일반화 (Cross-genre Evaluation)

- 한 장르(예: FPS)로 학습 → 다른 장르(MOBA, RPG)로 테스트
- taxonomy-free 설계의 핵심 주장 검증
- Video GEBD 대비 오디오 접근의 일반화 우위 측정

### 5.4 실험 4 — Ablation Study

|제거 요소|확인 내용|
|---|---|
|BEATs → Log Mel only|사전학습 피처의 기여도|
|BEATs frozen → fine-tuning|장르 과적합 여부|
|CEA 제거|예측 기반 경계 감지의 효과|
|OBD → fixed threshold|동적 threshold의 기여도|
|EST Loss 제거|각 손실 함수의 기여도|

### 5.5 평가 지표

- **F1 score** (Rel. Dis threshold 0.05 ~ 0.5, GEBD 표준 프로토콜)
- **Precision / Recall** (경계 위치 정확도)
- **Latency** (실시간 처리 지연시간, Online 설정)

## 7. 한계 및 향후 연구

### 한계

- 무음 또는 배경음만 있는 장면에서의 경계 감지 어려움
- 사운드 이펙트가 없는 순수 내러티브 장면(컷신 등) 대응 미흡
- 현재 Audio-only → 비주얼 정보 활용 불가

### 향후 연구

- **Audio-Visual Fusion GEBD**: 오디오를 주 신호로, 비주얼을 보조 신호로 활용하는 멀티모달 접근
- **실제 게임 디바이스 배포**: 온디바이스 경량화(knowledge distillation, 모델 pruning)
- **Downstream task 연결**: EBD 결과를 이용한 자동 하이라이트 생성, 게임 플레이 요약
