# Sound Event Detection and Time-Frequency Segmentation from Weakly Labelled Data

> Kong, Q., Xu, Y., Sobieraj, I., Wang, W., & Plumbley, M. D. (2019).
> **IEEE/ACM Transactions on Audio, Speech, and Language Processing**, 27(4), 777–791.
> arXiv: [1804.04715](https://arxiv.org/abs/1804.04715)

---

## 1. 핵심 요약 (What / How / Why)

| | |
|---|---|
| **What** | Weakly label(클립 단위 존재 여부 태그만 있는 데이터)로 학습해, 사운드 이벤트의 onset/offset 시점과 time-frequency 범위를 동시에 추정한다. |
| **How** | CNN으로 log mel spectrogram → T-F segmentation mask를 생성하고, Global Weighted Rank Pooling(GWRP)으로 클립 단위 예측을 수행하는 두 단계 프레임워크를 구성한다. |
| **Why** | 실제 SED 데이터셋의 대부분은 onset/offset 주석이 없는 weak label만 존재한다. 강한 주석 없이 temporal localization과 T-F 분리를 함께 달성하는 방법이 필요하다. |

---

## 2. 문제 정의

기존 SED 연구는 **strong label**(onset/offset 시간 주석)을 요구한다.
그러나 대규모 실세계 데이터셋(예: AudioSet, DCASE)은 대부분 **weak label** — 클립 안에 해당 이벤트가 존재하는지 여부만 — 을 제공한다.

이 논문은 세 가지 과제를 동시에 해결하는 것을 목표로 한다:

1. **Audio Tagging** – 클립 단위 클래스 분류
2. **Frame-wise / Event-wise SED** – 이벤트의 temporal localization (onset/offset)
3. **T-F Segmentation** – 이벤트가 발생한 time-frequency 영역의 마스크 추정

---

## 3. 방법론

### 3.1 입력 표현

- **Log mel spectrogram**: 오디오 신호를 $T \times F$ 행렬로 변환 ($T$: 시간 프레임, $F$: mel 필터 수)

### 3.2 Segmentation Mapping (CNN)

CNN을 적용해 입력 spectrogram $X \in \mathbb{R}^{T \times F}$에서 각 클래스 $k$에 대한 T-F 마스크 $M_k \in [0,1]^{T \times F}$를 생성한다.

$$M_k = \text{CNN}_k(X)$$

마스크는 이벤트가 발생하는 시간-주파수 영역을 soft하게 표시하며, 이 마스크와 원본 spectrogram의 element-wise product가 해당 이벤트의 분리된 표현이 된다.

### 3.3 Classification Mapping (GWRP)

T-F 마스크에서 클립 단위 확률을 집계하기 위해 **Global Weighted Rank Pooling (GWRP)**을 사용한다.

- 마스크 $M_k$의 각 원소를 내림차순으로 정렬하고, 순위에 따라 감소하는 가중치를 부여한다.
- Global Average Pooling(GAP)보다 상위 활성화에 더 집중할 수 있어, 짧게 발생하는 이벤트 탐지에 유리하다.

$$\hat{y}_k = \sum_{i} w_i \cdot M_k^{(i)}, \quad w_i \propto r^{i-1} \quad (0 < r < 1)$$

여기서 $r$은 rank decay 계수 (하이퍼파라미터).

### 3.4 학습

- **손실 함수**: Binary Cross-Entropy (클립 단위 weak label 사용)
- Temporal 주석 없이 end-to-end 학습 가능
- 추론 시 T-F 마스크에서 임계값을 통해 onset/offset 추출

## 4. 실험 설정

| 항목 | 내용 |
|---|---|
| **데이터셋** | DCASE 2018 Task 1 (acoustic scene) + Task 2 (sound events) 혼합 |
| **혼합 조건** | SNR 0 dB (background: foreground = 1:1) |
| **Baseline** | Fully Connected DNN |
| **평가 지표** | F1 score (Audio tagging / Frame-wise SED / Event-wise SED / T-F segmentation) |

---

## 5. 결과

| 평가 항목 | 제안 방법 | DNN Baseline |
|---|---|---|
| Audio Tagging F1 | **0.534** | 0.331 |
| Frame-wise SED F1 | **0.398** | 0.237 |
| Event-wise SED F1 | **0.167** | 0.120 |
| T-F Segmentation F1 | **0.218** | — (불가) |

- 모든 항목에서 baseline 대비 유의미한 성능 향상
- T-F segmentation은 baseline이 아예 수행할 수 없는 novel capability

---

## 6. 기여 및 의의

1. **Weak label만으로 T-F 마스크 학습** 가능함을 최초로 보임
2. **GWRP** 도입으로 짧은 이벤트에도 강인한 클립 단위 분류 가능
3. T-F 마스크를 이용해 **소리 분리(source separation)** 를 부산물로 획득
4. onset/offset 추출, T-F segmentation, audio tagging을 **단일 프레임워크**로 통합

---

## 7. 한계 및 비판

- 실험이 **DCASE 2018 한 가지 조건(0 dB)**에 국한되어 일반화 검증이 부족
- Event-wise F1 (0.167)이 절대값 기준으로 여전히 낮아 실용성에 의문
- GWRP의 rank decay 계수 $r$ 선택에 대한 민감도 분석 부재
- 다수의 이벤트가 동시에 겹치는 경우(polyphonic) 마스크 분리 성능 미검증

---

## 8. 내 연구와의 연결

- 본 논문은 **weak label + T-F 표현 → SED**의 기초 프레임워크를 제공한다.
- 게임 비디오는 배경 BGM + 이벤트 SFX가 혼재하므로, 이 T-F segmentation 접근이 게임 오디오 이벤트 경계 탐지에 직접 적용 가능하다.
- 특히 게임 SFX는 반복적이고 설계된 패턴을 가지므로, T-F 마스크 학습이 더 잘 수렴할 가능성이 있다.
- GWRP 대신 Attention 기반 pooling으로 교체하는 것이 성능 향상의 방향이 될 수 있다.
