## 방법론 정리

### 전체 파이프라인

```
Audio Input (mixture.wav)
        ↓
[Source Separation]  cocktail-fork (MRX model)
        ↓
  music / sfx / speech stems
        ↓
[Per-stem MFCC + SSM Novelty]
        ↓
[Per-clip Adaptive Threshold]
        ↓
[NMS Voting (min_votes=3)]
        ↓
Predicted Boundaries
```

---

### Step 1: Source Separation

cocktail-fork를 사용해 mixture 오디오를 3개 semantic stream으로 분리합니다.

```
mixture → music, sfx, speech
```

총 4개 stem (mixture 포함) 이 각각 독립적인 경계 감지기로 작동합니다.

---

### Step 2: MFCC + SSM Novelty Curve

각 stem에 대해 동일한 방식으로 novelty curve를 계산합니다.

```
stem audio
    ↓
MFCC (n=20, hop=512)           # frame-level feature
    ↓
Segment averaging               # WS=2.0s, HS=0.33s
    ↓
Self-Similarity Matrix (SSM)    # cosine similarity
    ↓
Checkerboard kernel (k=10)      # 경계 감지
    ↓
Novelty curve (0.33s 해상도)
```

**WS=2.0s** 선택 이유: 게임 영상의 장면 텍스처를 포착하기에 3.0s보다 적절한 context 길이. SSM에서 half-window reflection padding을 사용해 클립 전체 구간을 커버합니다.

---

### Step 3: Per-clip Adaptive Threshold

클립마다 오디오 다이나믹스가 다르기 때문에 고정 threshold 대신 **per-clip percentile**을 사용합니다.

```python
threshold_stem = percentile(novelty_curve_stem, p_stem)
```

stem별 percentile은 다르게 설정합니다:

|Stem|Percentile|근거|
|---|---|---|
|mixture|82|전체 신호 기준|
|music|75|BGM 변화는 중간 강도 신호|
|sfx|**95**|효과음은 peak가 뚜렷할 때만 신뢰|
|speech|**70**|대화 변화는 약한 신호 → 관대하게|

sfx는 엄격하게(FP 방어), speech는 관대하게(독립 coverage 확보)하는 **비대칭 구조**입니다.

---

### Step 4: Peak Detection + NMS Voting

각 stem의 novelty curve에서 peak를 탐지한 뒤, NMS로 클러스터링하고 **3개 이상의 stem이 동의한 시점**만 경계로 채택합니다.

```
각 stem → peak detection (distance: stem별 최소 간격)
        ↓
전체 후보 합산 → tol=2.0s 범위 내 클러스터링
        ↓
votes ≥ 3인 클러스터만 채택
```

stem별 최소 peak 간격:

|Stem|distance|
|---|---|
|mixture|2.5s|
|music|2.5s|
|sfx|**7.5s** (UI 효과음은 간격이 넓음)|
|speech|3.5s|

### 핵심 contribution 포인트

1. **Source separation을 통한 semantic stream 분리**: mixture만 쓰는 기존 방식 대신 music/sfx/speech를 독립 감지기로 활용
2. **Per-clip adaptive threshold**: 클립별 novelty 분포를 기준으로 threshold를 자동 조정 → 새 영상에도 일반화 가능 (LOOV gap=0.008)
3. **비대칭 stem 역할**: sfx(FP 방어) + speech(독립 coverage) 구조가 NMS에서 서로 보완

# **전체 실험 결과 요약**

---

### 실험 설정

- **Train**: 3개 영상 (ZmlZCMn7Jjw, _R5IdnlZ0R4, bg8i4CvE74M), 28 clips, 74 GT boundaries
- **Hold-out Test**: 2개 영상 (aySPmEBzlS4, 3PB0f8k_Yxw), 11 clips, 29 GT boundaries
- **GT 기준**: 3명 어노테이터, min_agreement=2, tolerance=2.0s
- **Feature**: MFCC (20차) + SSM + Checkerboard kernel novelty

---

### 비교 방법론 3가지

**Method A — Mixture only (WS=2.0, HS=0.75)**

- Source separation 없이 mixture 오디오만 사용
- Train에서 WS/HS/threshold를 모두 grid search로 최적화
- Full-data에서 가장 높은 수치(0.587)지만 실제로는 과적합

**Method B — Stem fusion, uniform HS=0.33**

- mixture/music/sfx/speech 4개 stem 독립 투표, votes=3
- 모든 stem에 동일한 WS=2.0, HS=0.33 적용
- Per-clip adaptive percentile threshold

**Method C — Stem fusion, per-stem WS/HS**

- 각 stem에 최적 WS/HS 독립 적용 (mixture=2.0/0.75, music=2.5/0.75, sfx=2.5/0.5, speech=2.0/0.5)
- 탐색 공간이 가장 넓음

---

### 핵심 결과

||Full-data|LOOV CV|Hold-out|LOOV gap|Hold-out gap|
|---|---|---|---|---|---|
|A: Mixture only|0.587|0.510|0.271|0.077|**0.285**|
|B: Stem fusion uniform|0.549|**0.540**|0.380|**0.009**|**0.170**|
|C: Stem fusion per-stem|0.563|0.497|**0.405**|0.066|0.187|
|Baseline (orig)|0.448|—|—|—|—|

---

### 결론

1. **Full-data 수치만 보면 A가 최강이지만 착시**입니다. LOOV에서 gap=0.077, hold-out에서 gap=0.285로 심각한 과적합이 드러납니다. HS=0.75가 특정 영상의 오디오 특성에 맞춰진 것입니다.
    
2. **Method B (stem fusion)가 일반화 측면에서 압도적**입니다. LOOV gap=0.009, hold-out gap=0.170으로 세 방법 중 가장 안정적입니다. 4개 stem의 voting 구조가 implicit regularization으로 작용합니다.
    
3. **Method C는 hold-out 성능(0.405)은 가장 높지만** 탐색 공간이 넓어 LOOV에서 오히려 C가 B보다 낮습니다(0.497 vs 0.540). 더 많은 데이터가 있다면 C가 유리할 수 있습니다.
    
4. **논문 contribution 포인트**: "오디오 source separation을 통해 얻은 stem별 novelty를 독립 voter로 활용하는 구조가, 단일 mixture 대비 파라미터 과적합을 억제하고 새로운 영상에 대한 일반화 능력을 향상시킨다" — 이를 LOOV CV와 hold-out 두 가지 평가로 정량적으로 검증.
