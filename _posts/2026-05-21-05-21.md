## 예심 피드백 요약

1. **설명의 명확성 부족** — 교수님이 내용을 이해하기 어렵다고 하셨음. PPT에서 예시 위주로 설명하는 방식으로 개선 필요.
2. **추가 실험 요청** — 직접 구축한 게임 데이터셋 외에, 공개된 일반 영상 데이터셋에도 동일한 파이프라인을 적용했을 때 결과를 비교해보기를 권장하심.
   - 핵심 질문: 오디오 기반 파이프라인이 게임 영상에서 잘 동작하는 게 "게임 오디오의 특수성 때문"인지, 아니면 "일반적인 방법론이 원래 잘 되는 것"인지?
3. **Motivation 강화** — Game video와 Kinetics video를 DDM-net Graph로 비교하여 게임 영상의 오디오 특성 차이를 시각적으로 보여줄 것.

---

## 1. 어떤 데이터셋을 추가로 활용할 것인가?

### 방향
교수님 제안의 핵심은 **도메인 비교**다. 게임 영상에서 오디오 기반 경계 검출이 의미 있으려면, 게임 오디오가 일반 영상 오디오와 다르게 작동한다는 근거가 있어야 한다.

### 후보 데이터셋

| 데이터셋 | 특성 | 활용 목적 |
|---|---|---|
| **AIHub 일반 영상 데이터셋** | 교수님이 직접 링크 제공한 공개 데이터 | 일반 영상에서 파이프라인 성능 확인 |
| **Kinetics-GEBD** | DDM-net이 학습된 기반 데이터 | Motivation용 DDM-net Graph 비교 |
| **현재 Holdout (Portal2, Doom)** | 이미 보유 중인 다른 장르 게임 데이터 | 게임 내 장르 간 일반화 참고 |

> 우선순위: **Kinetics-GEBD 일부 샘플** → DDM-net Graph 비교로 Motivation에 활용.  
> **AIHub 데이터셋**은 파이프라인 적용 실험에 활용.

---

## 2. 게임 데이터셋을 더 확보할 것인가?

### 결론: 당장 추가 구축보다 비교 실험에 집중

현재 게임 데이터셋 (123 clips, 361 GT boundaries)은 어노테이션까지 완료된 상태다. 추가 게임 장르 데이터를 새로 구축하면:
- 어노테이션 비용(시간, 인력)이 크다.
- 본심까지 남은 시간 내에 완료하기 어렵다.
- 이미 Holdout으로 Portal2, Doom (11 clips, 27 GT boundaries)이 있어 제한적 일반화 참고는 가능하다.

따라서 **새 게임 데이터 구축보다, 일반 영상 데이터셋과의 비교에 집중**하는 것이 현실적이다.

---

## 3. 어떤 실험을 진행할 것인가?

### 실험 A: DDM-net Graph 비교 (Motivation 강화)

- **목적**: 게임 영상과 일반 영상(Kinetics)의 오디오 특성 차이를 시각적으로 보여줌.
- **방법**: 같은 DDM-net을 게임 클립과 Kinetics 클립에 각각 적용, novelty score 분포를 그래프로 비교.
- **기대 결과**: 게임 영상은 상태 전환 시 오디오 novelty가 뚜렷하게 spike되고, 일반 영상은 더 분산적이거나 다른 패턴을 보임 → 게임 오디오 특수성 근거 확보.
- **위치**: 논문 Motivation 또는 3장(Task 정의) 섹션에 삽입.

### 실험 B: 일반 영상 데이터셋에서의 파이프라인 성능

- **목적**: 동일한 오디오 기반 파이프라인이 일반 영상에서는 어떤 성능을 보이는지 확인.
- **방법**: AIHub 데이터셋의 일부 클립에 현재 파이프라인(Mixture SFX stem + Speech Fusion 또는 DDM-Net) 적용.
- **기대 결과 (가설)**:
  - 게임 영상: 오디오가 상태 전환 시 명확히 변화 → 경계 검출 성능 양호.
  - 일반 영상: 오디오 변화 패턴이 다르거나 경계가 오디오로 잘 드러나지 않음 → 성능 상대적으로 낮거나 다름.
- **해석 방향**: 결과가 게임보다 낮으면 "게임 오디오 특수성" 주장 강화. 비슷하거나 높으면 파이프라인의 일반성을 보여주는 결과로 재해석 가능.

---

## 4. 왜 이런 실험을 진행하는가?

### 논문 기여 측면에서의 필요성

현재 논문의 핵심 주장은:
> "게임 플레이 영상은 상태 전환 경계가 오디오에 뚜렷하게 반영되며, 오디오 기반 파이프라인으로 효과적으로 검출할 수 있다."

그런데 심사 위원이 자연스럽게 물을 수 있는 반박:
- "그냥 일반적인 오디오 방법이 원래 잘 되는 거 아닌가요?"
- "게임 영상이 특별한 이유가 뭔가요?"

이 실험들은 **이 반박에 대한 실증적 답변**을 제공한다.

### 피드백과의 연결

교수님이 요청한 건 "다른 데이터에서도 실험해보기"였지만, 그 이면은 **방법론의 도메인 특화성 또는 일반성을 검증**하라는 것이다. 단순히 결과를 보여주는 게 아니라, 비교를 통해 게임 오디오가 왜 경계 검출에 유리한지를 설명하는 근거를 마련하는 것이 목적이다.

## 5. 논문에 어떤 내용을 추가할 것인가?

### 추가 위치 및 내용

| 섹션 | 추가 내용 |
|---|---|
| **Motivation / Introduction** | Game video vs Kinetics video DDM-net novelty score 비교 그래프. 게임 오디오의 상태 전환 시 spike 패턴을 시각화. |
| **5장 (GEBD 모델의 게임 도메인 적용 분석)** | DDM-net이 Kinetics에서 학습되었으나 게임 도메인에서 다르게 동작하는 이유 분석. |
| **7장 (실험)** | 일반 영상 데이터셋(AIHub)에 파이프라인 적용 결과 추가. 게임 vs 일반 영상 성능 비교 표. |
| **9장 (논의)** | 오디오 기반 접근이 게임 특화적인 이유, 일반화 한계, 향후 방향 서술. |

## 게임에서 의미있는 경계 시점의 정의

이 질문은 논문의 Task 정의 섹션(3장)과 직결된다.

### 현재 정의 (어노테이션 기반)

2명 이상의 어노테이터가 2초 tolerance 내에서 동의한 시점을 경계로 정의 (tol2s_min2). 이 기준은 **어노테이터 간 합의**로 정의된 경험적 경계다.

### 의미적 경계의 유형

게임플레이 영상에서 경계는 다음과 같은 게임 상태 전환에 대응한다:

| 경계 유형 | 오디오 변화 |
|---|---|
| 전투 시작 / 종료 | 전투 BGM 개시, SFX 급증 / 전투 음악 종료, 조용해짐 |
| 컷씬 시작 / 종료 | 대화음, 시네마틱 BGM 등장 / 조작 가능한 SFX 재개 |
| 메뉴 진입 / 복귀 | UI 클릭음, 배경음 소거 / 게임플레이 BGM 재개 |
| 사망 / 부활 | 사망 SFX, 침묵 구간 / 부활 SFX, BGM 재시작 |
| 새 구역 진입 | 환경 ambient 변화, 새 BGM 전환 |

### 정의의 한계와 논문에서의 처리 방식

- 어노테이터마다 반응 속도 차이 존재 (0.5~2초 human variation).
- "의미적 경계"를 명확히 정의하기 위해 2초 tolerance를 사용하되, 이는 어노테이터 간 human variation을 수용하는 실용적 기준임을 명시.
- 게임 상태 전환이 단일 시점보다 짧은 구간에 걸쳐 일어날 수 있으므로, tolerance 설정이 GT 품질에 미치는 영향(0.5s vs 2s trade-off)도 논의에 포함할 것.

## 우선순위 정리

1. **DDM-net Graph 비교 실험** (Motivation 강화) — 구현 난이도 낮음, 임팩트 큼.
2. **일반 영상 데이터셋 파이프라인 적용** — AIHub 데이터 다운로드 및 전처리 필요, 시간 소요.
3. **논문 Motivation / 논의 섹션 개선** — 실험 결과 나온 후 작성.
4. **PPT 설명 방식 개선** — 예시 중심, 수식 최소화.
