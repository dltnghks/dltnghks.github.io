## 핵심 개념

컴퓨터는 숫자나 글자를 직접 이해하지 않는다.
전기 신호의 두 상태를 0과 1로 약속하고, 이 비트의 조합을 정해진 규칙에 따라 해석한다.

## 1. 비트, 바이트, 2진수

### 비트와 바이트

**비트(bit)** 는 컴퓨터가 구분할 수 있는 가장 작은 정보 단위로, `0` 또는 `1` 하나를 표현한다.

**바이트(byte)** 는 일반적으로 8비트의 묶음이다. 8개의 비트가 각각 두 상태를 가질 수 있으므로, 1바이트는 총 $2^8 = 256$가지 값을 표현할 수 있다.

| 단위 | 비트 수 | 표현 가능한 경우의 수 |
| --- | ---: | ---: |
| 1비트 | 1 | 2개 |
| 1니블(nibble) | 4 | 16개 |
| 1바이트(byte) | 8 | 256개 |
| 2바이트 | 16 | 65,536개 |

> [!note] C 언어의 바이트
> 현대 컴퓨터에서는 보통 1바이트가 8비트다. 다만 C 언어에서 바이트는 `char` 하나의 크기를 뜻하며, 모든 환경에서 정확히 8비트여야 하는 것은 아니다.

### 2진수의 자릿값

10진수는 각 자리가 $1$, $10$, $100$처럼 10의 거듭제곱을 뜻한다.  
2진수는 각 자리가 $1$, $2$, $4$, $8$, $16$처럼 2의 거듭제곱을 뜻한다.

| 자리 | $2^3$ | $2^2$ | $2^1$ | $2^0$ |
| --- | ---: | ---: | ---: | ---: |
| 자릿값 | 8 | 4 | 2 | 1 |
| `1101₂` | 1 | 1 | 0 | 1 |

따라서 $1101_2 = 8 + 4 + 1 = 13_{10}$ 이다. 8비트로 표현하면 `13`은 `00001101`이다.

```text
128  64  32  16   8   4   2   1
 0   0   0   0   1   1   0   1

00001101₂ = 8 + 4 + 1 = 13₁₀
```

### n비트가 표현할 수 있는 범위

부호 없는 정수에서 n비트가 표현할 수 있는 값은 $0$부터 $2^n - 1$까지다.

|비트 수|표현 범위|
|---|---|
|4비트|0 ~ 15|
|8비트|0 ~ 255|
|16비트|0 ~ 65,535|

음수를 포함하는 부호 있는 정수는 뒤에서 2의 보수 방식으로 다룬다.

### 16진수

2진수는 길어지기 때문에 4비트씩 묶어 16진수로 자주 표현한다.

```
2진수:  0000 1101
16진수:    0    D

00001101₂ = 0x0D = 13₁₀
```

### C 예제: 정수 13을 비트열로 출력하기

```C
#include <stdint.h>
#include <stdio.h>

static void print_binary(uint8_t value) {
    for (int bit = 7; bit >= 0; --bit) {
        putchar((value & (1u << bit)) != 0 ? '1' : '0');
    }
}

int main(void) {
    uint8_t value = 13;

    printf("decimal: %u\n", (unsigned)value);
    printf("hex: 0x%02X\n", (unsigned)value);
    printf("binary: ");
    print_binary(value);
    putchar('\n');
}
```

```
decimal: 13
hex: 0x0D
binary: 00001101
```

`value`는 숫자 `13`으로 선언됐지만, 메모리에는 `00001101`이라는 비트 패턴으로 저장된다. 10진수·2진수·16진수는 같은 값을 서로 다르게 적는 표기법이다.

## 2. 비트열의 의미는 문맥이 결정한다

예를 들어 `11111111`은 해석 규칙에 따라 달라진다.

|해석 규칙|의미|
|---|---|
|부호 없는 8비트 정수|255|
|2의 보수 부호 있는 정수|-1|
|색상 채널 값|가장 강한 밝기|
|문자 인코딩의 일부|문자 데이터를 구성하는 바이트|

즉, 컴퓨터가 저장하는 것은 비트열이고, 그 비트열을 무엇으로 볼지는 프로그램과 데이터 형식이 결정한다.

## 3. 정보별 표현 방식

- 정수: 2진수와 부호 표현
- 문자: 문자 인코딩(ASCII, Unicode, UTF-8)
- 이미지: 픽셀마다 색상 값(RGB)을 저장
- 소리: 일정한 시간 간격으로 측정한 진폭 값(샘플)을 저장
- 프로그램: CPU가 실행할 명령어를 기계어 형태로 저장

### 3.1 현실의 정보는 비트열로 바뀐다

|단계|설명|예시|
|---|---|---|
|정보|사람이 다루는 의미 있는 대상|문자 `A`, 숫자 `65`, 사진, 소리|
|인코딩|정보를 비트열로 바꾸는 약속|ASCII, UTF-8, RGB, PCM|
|비트열|컴퓨터가 저장·계산·전송하는 형태|`01000001`|
|디코딩|비트열을 규칙에 따라 읽는 과정|문자 `A` 또는 숫자 `65`|

#### 같은 비트열도 해석 규칙에 따라 달라진다

|비트열|해석 규칙|의미|
|---|---|---|
|`01000001`|부호 없는 8비트 정수|65|
|`01000001`|ASCII 문자 코드|`A`|
|`01000001`|8비트 색상 채널 값|밝기 65|

### C17 예제: `0x41`을 숫자와 문자로 읽기

```
#include <stdint.h>
#include <stdio.h>

static void print_bits(uint8_t value) {
    for (int bit = 7; bit >= 0; --bit) {
        putchar((value & (1u << bit)) != 0 ? '1' : '0');
    }
}

int main(void) {
    uint8_t bits = 0x41;  // 01000001

    printf("bits: ");
    print_bits(bits);
    printf("\nnumber: %u\n", (unsigned)bits);
    printf("character: %c\n", (int)bits);
}
```

```
bits: 01000001
number: 65
character: A
```




### 3.2 정수 : 부호 없는 정수

**부호 없는 정수(unsigned integer)** 는 음수를 표현하지 않고, `0`과 양의 정수만 표현하는 방식이다.
모든 비트가 값의 크기를 표현하는데 사용된다.

n비트의 부호 없는 정수는 다음 범위를 표현한다.

$$
0 \sim 2^n - 1
$$

| 비트 수 | 최소값 | 최대값 |
| ---: | ---: | ---: |
| 4비트 | 0 | 15 |
| 8비트 | 0 | 255 |
| 16비트 | 0 | 65,535 |


8비트에서는 각 비트가 다음 값을 가진다.

```text
128  64  32  16   8   4   2   1
 0   0   0   0   1   1   0   1

00001101₂ = 8 + 4 + 1 = 13₁₀
```

가장 큰 8비트 부호 없는 정수는 모든 비트가 1인 경우다.

```
11111111₂ = 128 + 64 + 32 + 16 + 8 + 4 + 2 + 1
          = 255₁₀
```
즉, 8비트에서는 256을 저장할 수 없다. 256은 2진수로 `1 00000000`이며, 표현하려면 9비트가 필요하다.

#### 범위를 넘으면 어떻게 될까?
8비트 값 `255`에 `1`을 더하면 계산 결과는 `256`이다. 하지만 저장 공간이 8비트뿐이라면 가장 왼쪽의 9번째 비트는 저장할 수 없고, 아래 8비트만 남는다.

```
  11111111  = 255
+ 00000001  =   1
----------
1 00000000  = 256

저장되는 하위 8비트: 00000000 = 0
```

이처럼 표현 범위를 넘어 값이 다시 처음으로 돌아가는 현상을 **오버플로(overflow)** 라고 한다.

### C17 예제: `uint8_t`의 범위

```C
#include <stdint.h>
#include <stdio.h>

static void print_binary(uint8_t value) {
    for (int bit = 7; bit >= 0; --bit) {
        putchar((value & (1u << bit)) != 0 ? '1' : '0');
    }
}

int main(void) {
    uint8_t maximum = UINT8_MAX;
    uint8_t wrapped = (uint8_t)((unsigned)maximum + 1u);

    printf("maximum: %u (", (unsigned)maximum);
    print_binary(maximum);
    printf(")\n");

    printf("after +1: %u (", (unsigned)wrapped);
    print_binary(wrapped);
    printf(")\n");
}
```

```
maximum: 255 (11111111)
after +1: 0 (00000000)
```
`uint8_t`는 정확히 8비트인 부호 없는 정수형이다. 위 코드에서 `255 + 1`의 결과인 `256`을 다시 `uint8_t`에 저장하면, C 언어 규칙에 따라 $256 \bmod 256 = 0$이 저장된다.

> [!warning] 부호 없는 정수는 음수를 표현하지 않는다  
> `11111111`은 부호 없는 8비트 정수로 해석하면 `255`이다. 같은 비트열을 부호 있는 정수로 해석하면 보통 `-1`이 될 수 있다.

### 3.3 정수: 부호 있는 정수와 2의 보수
부호 없는 정수는 `0`과 양수만 표현할 수 있다. 하지만 온도, 잔액, 좌표처럼 음수가 필요한 정보도 많다. **부호 있는 정수(signed integer)** 는 양수와 음수를 함께 표현하는 방식이다.
현대 컴퓨터는 대부분 **2의 보수(two's complement)** 를 사용한다.

#### 8비트 부호 있는 정수의 범위
8비트는 총 256가지 비트 패턴을 표현할 수 있다. 2의 보수에서는 이 패턴을 음수와 양수에 다음처럼 나눈다.

| 비트열 | 값 |
| --- | ---: |
| `00000000` | 0 |
| `01111111` | 127 |
| `10000000` | -128 |
| `11111111` | -1 |

따라서 8비트 부호 있는 정수의 범위는 다음과 같다.

$$
-128 \sim 127
$$

양수는 `0`부터 `127`까지 128개, 음수는 `-1`부터 `-128`까지 128개다. `+128`이 없기 때문에 범위가 완전히 대칭이지 않다.

#### 음수 만들기 : 비트를 반전하고 1을 더한다.

8비트에서 `-5`를 표현해 보자.
```text
 5  = 00000101
비트 반전 = 11111010
      +1 = 11111011

-5  = 11111011
```
같은 결과를 수식으로도 구할 수 있다.
$$ 2^8 - 5 = 256 - 5 = 251 $$
`251`의 2진수는 `11111011`이므로, 8비트 2의 보수에서 이 비트열은 `-5`를 뜻한다.

#### 최상위 비트의 의미

2의 보수에서는 최상위 비트가 단순히 “음수 표시”만 하는 것이 아니다. 8비트에서는 최상위 비트가 $-128$의 자릿값을 가진다.

```
11111011₂
= -128 + 64 + 32 + 16 + 8 + 2 + 1
= -5
```

#### 덧셈 회로로 뺄셈하기

2의 보수를 사용하면 덧셈 회로만으로 뺄셈을 처리할 수 있다.

```
  00000101  =  5
+ 11111011  = -5
----------
1 00000000

하위 8비트: 00000000 = 0
```

9번째 자리의 올림은 8비트 저장 공간에 들어가지 않는다. 따라서 `5 + (-5)`의 결과는 `0`이 된다.

### C17 예제: `-5`의 2의 보수 표현

```C
#include <stdint.h>
#include <stdio.h>

static void print_binary(uint8_t value) {
    for (int bit = 7; bit >= 0; --bit) {
        putchar((value & (1u << bit)) != 0 ? '1' : '0');
    }
}

int main(void) {
    int8_t signed_value = -5;
    uint8_t encoding = (uint8_t)signed_value;

    printf("signed value: %d\n", (int)signed_value);
    printf("unsigned encoding: %u\n", (unsigned)encoding);

    printf("bits: ");
    print_binary(encoding);
    putchar('\n');
}
```

```
signed value: -5
unsigned encoding: 251
bits: 11111011
```

`(uint8_t)signed_value` 변환은 `-5`에 256을 더한 `251`을 만든다. 일반적인 2의 보수 시스템에서 `251`의 비트열 `11111011`은 `int8_t`의 `-5`를 표현하는 방식과 같다.

> [!warning] C 언어의 부호 있는 오버플로  
> `int8_t`의 범위를 넘는 덧셈을 “비트가 한 바퀴 돌아간다”고 가정하면 안 된다. C에서 부호 있는 정수의 오버플로는 정의되지 않은 동작이다. 위 예제는 범위 안의 값과 부호 없는 변환만 사용하므로 안전하다.
### 3.4 실수 : 고정소수점과 부동소수점
정수는 비트로 정확하게 표현할 수 있지만, `13.25`, `0.1`, `-3.14`처럼 소수점이 있는 값은 별도의 표현 방식이 필요하다.
실수를 표현하는 대표적인 방식은 **고정소수점(fixed-point)**과 **부동소수점(floating-point)** 이다.

| 구분      | 고정소수점          | 부동소수점             |
| ------- | -------------- | ----------------- |
| 소수점 위치  | 항상 고정          | 지수에 따라 이동         |
| 표현 범위   | 비교적 작음         | 매우 넓음             |
| 정밀도     | 전체 범위에서 일정한 간격 | 값이 커질수록 표현 간격도 커짐 |
| 소수의 정확성 | 정한 단위 안에서는 정확  | 많은 10진수 소수가 근삿값   |
| 대표 용도   | 금액, 센서값, 임베디드  | 과학 계산, 그래픽, 머신러닝  |
#### 고정소수점
고정소수점은 소수점 위치를 미리 정한다. 예를 들어 금액을 원 단위 대신 센트 단위 정수로 저장할 수 있다.
```text
저장된 정수: 1325
소수점 위치: 뒤에서 두 자리
실제 값: 13.25
```

`1325`와 `75`를 더하면 정수 연산으로 정확히 `1400`을 얻는다. 이를 다시 소수점 둘째 자리로 읽으면 `14.00`이다.

고정소수점은 소수점 위치가 변하지 않으므로 이해하기 쉽고 일정한 단위의 값을 정확하게 다룰 수 있다. 반면 매우 큰 값과 매우 작은 값을 동시에 표현하기 어렵다.

> [!note] 고정소수점도 모든 소수를 정확히 표현하는 것은 아니다  
> 예를 들어 2진수 고정소수점은 `1/2`, `1/4`처럼 분모가 2의 거듭제곱인 값은 정확히 표현하지만, `0.1`은 정확히 표현할 수 없다. 금액을 센트 단위 정수로 저장하는 방식은 10진수 기준으로 소수 둘째 자리까지 정확하게 다루기 위한 별도의 스케일링 방법이다.

#### 부동소수점
부동소수점은 값을 다음과 같이 표현한다.

```
부호 × 유효숫자 × 2지수
```

10진수 과학적 표기법과 비슷하다.

```
1234.5 = 1.2345 × 10³
```

2진수에서는 `13.25`를 다음처럼 정규화한다.

```
13.25₁₀ = 1101.01₂
        = 1.10101₂ × 2³
```

`× 2³`은 이진 소수점을 오른쪽으로 세 칸 옮기는 것과 같다.

```
1.10101₂ × 2¹ = 11.0101₂
1.10101₂ × 2² = 110.101₂
1.10101₂ × 2³ = 1101.01₂
```

따라서 `1101.01₂`은 다음 값이다.

```
8 + 4 + 1 + 1/4 = 13.25
```

#### IEEE 754 단정도 `float`

현대 컴퓨터의 `float`은 대부분 IEEE 754 단정도 형식으로, 총 32비트를 사용한다.

|구성 요소|비트 수|역할|
|---|---|---|
|부호(sign)|1|양수 또는 음수|
|지수(exponent)|8|이진 소수점의 이동량|
|가수(fraction)|23|유효숫자의 세부 비트|

정규화된 일반 값은 다음 식으로 해석한다.

$$(-1)^S \times \left(1 + \frac{F}{2^{23}}\right) \times 2^{E-127}$$


- `S`: 부호 비트
- `F`: 가수 23비트를 부호 없는 정수로 읽은 값
- `E`: 저장된 지수 값
- `E - 127`: 실제 지수

지수는 8비트이므로 `0 ~ 255`을 저장할 수 있다. 하지만 `0`과 `255`은 0·무한대·NaN 같은 특수값에 사용된다.

```
일반적인 실제 지수 범위: -126 ~ +127
```

즉, 지수 8비트는 소수점을 8칸만 이동하는 것이 아니다. 일반적인 `float`은 이진 소수점을 왼쪽으로 최대 126칸, 오른쪽으로 최대 127칸 정도 이동할 수 있다.

### `13.25`를 IEEE 754 방식으로 보기

```
13.25₁₀ = 1.10101₂ × 2³

부호: 0
실제 지수: 3
저장 지수: 3 + 127 = 130 = 10000010₂
가수: 10101000000000000000000
```

정규화된 수는 맨 앞의 `1`이 항상 존재하므로 저장하지 않는다. 따라서 가수 필드에는 `1.10101₂`에서 소수점 뒤의 `10101`만 저장한다.


## 4. 정리

컴퓨터가 실제로 다루는 것은 0과 1의 비트열이다.  
숫자, 문자, 이미지, 소리, 명령어는 모두 비트열을 해석하는 방식의 차이일 뿐이다.
