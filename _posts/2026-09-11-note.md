## 운영체제란?

운영체제(Operating System, OS)는 사용자와 응용 프로그램이 하드웨어를 안전하고 효율적으로 사용할 수 있게 중재하는 **시스템 소프트웨어**다.

컴퓨터의 CPU, 메모리, 저장장치, 입출력 장치는 한정되어 있다. 운영체제는 여러 프로그램이 이 자원을 함께 쓰는 상황에서 자원을 배분하고, 프로그램끼리 서로 침범하지 않도록 보호한다.

> 운영체제는 하드웨어를 추상화하고, 자원을 관리하며, 프로그램 실행 환경을 제공한다.

### 운영체제가 필요한 이유

- **편의성**: 프로그램은 디스크·키보드·네트워크 장치를 직접 제어하지 않고, 운영체제가 제공하는 일관된 인터페이스를 사용한다.
- **효율성**: CPU 시간, 메모리, 입출력 장치를 상황에 맞게 배분해 시스템 전체 성능을 높인다.
- **보호와 안정성**: 한 프로그램의 오류나 악의적인 접근이 다른 프로그램·운영체제 자체에 영향을 주지 못하게 격리한다.
- **공정성**: 여러 프로세스가 동시에 실행될 때 특정 프로그램이 자원을 독점하지 않도록 조정한다.

### 핵심 역할

| 역할 | 설명 | 대표 주제 |
| --- | --- | --- |
| 프로세스 관리 | 실행 중인 프로그램의 생성, 종료, CPU 할당을 관리 | 프로세스, 스레드, 스케줄링 |
| 메모리 관리 | 제한된 메모리를 배분하고 보호 | 가상 메모리, 페이징 |
| 파일·저장장치 관리 | 데이터를 파일 단위로 저장하고 접근하게 함 | 파일 시스템, 디렉터리 |
| 입출력 관리 | 장치별 차이를 감추고 통일된 방식으로 제어 | 인터럽트, 드라이버 |
| 보호·보안 | 권한을 구분하고 자원 접근을 통제 | 사용자 모드, 커널 모드 |

### 큰 그림

`응용 프로그램 → 시스템 콜 → 운영체제 커널 → 하드웨어`

응용 프로그램은 보통 하드웨어에 직접 접근하지 않는다. 파일을 열거나, 메모리를 요청하거나, 네트워크 데이터를 보내는 작업은 **시스템 콜**을 통해 운영체제에 요청한다. 운영체제의 핵심 부분인 **커널(Kernel)** 이 요청을 검증하고 실제 하드웨어 동작을 수행한다.

> [!question] 확인
> 웹 브라우저가 파일을 저장할 때, 브라우저가 디스크를 직접 제어하지 않고 운영체제를 거치는 이유는 무엇일까?
