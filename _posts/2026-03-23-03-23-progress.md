## EfficientGEBD
### 입력
mp4 영상을 3프레임마다 1장 샘플링 (60fps → 20fps)
224×224 리사이즈 → ImageNet 정규화
각 프레임마다 앞뒤 10프레임 묶음(window) 을 함께 입력

### 추론
CSN(Channel-Separated Network) 백본으로 시각 특징 추출
각 프레임 위치에서 "전후 장면이 얼마나 다른가"를 비교해 0~1 사이 경계 score 출력

> **CSN(Channel-Separated Network)?**
> 비디오에서 시각 특징을 뽑는 **3D CNN 백본**
> 일반 이미지는 2D CNN(H×W)으로 특징을 뽑는데, 비디오는 시간 축이 추가돼서 3D CNN(H×W×T)이 필요하다. 그래서 CSN 사용


### 후처리
10프레임 window 내 score를 midmax 방식으로 집계 (중간 4프레임의 최대값)
연속으로 threshold(0.35) 넘는 구간을 하나의 그룹으로 묶음
그룹 내 score 최대 지점만 경계로 선택 (group_peaks)

>**midmax**?
>10프레임 중 앞 뒤 3개씩은 제외하고 가운데 4개 중 max값을 사용한다.

```python
## inference.py

# gradient를 추적하지 않게 하는 데코레이터
# 추론 과정이기 때문에 역전파하지 말라고 적어놓은 것
@torch.no_grad()
def main(args):
    device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
    model = E2EModel()
    # checkpoint
    state_dict = torch.load('E2EModel.pth')
    # 가중치 넣기
    model.load_state_dict(state_dict)

	# 모델 device에 올리기
    model = model.to(device)
    model.eval()

	# video 가져와서 정보들 가져왔음.
    imgs, frame_indices, fps, total_frames = load_video(args.video)
    seconds = total_frames / fps

	# 이미지들도 device에 올리기
    inputs = imgs.to(device)[None]
    scores = model(inputs)[0].cpu().numpy()

    threshold = args.threshold
    det_t = np.array(get_idx_from_score_by_threshold(threshold=threshold,
                                                     seq_indices=frame_indices,
                                                     seq_scores=scores)) / fps

    print(f'Video path: {args.video}')
    print(f'Sampled frames: {len(frame_indices)}')
    print(f'Video FPS: {fps:.0f}')
    print(f'Video Duration: {seconds:.1f}s')
    print(f'Number Boundaries: {len(det_t)}')
    print(list(map(lambda t: round(t, 1), det_t)))
```

## DDM-net

### 입력
프레임을 미리 이미지로 추출해서 디스크에 저장 (kinetics_GEBD_RGB/)
DataAssets/multi-frames-GEBD-test-5.pkl — 각 프레임 중심으로 앞뒤 5프레임씩 묶은 멀티프레임 묶음

### 추론
ResNet 백본으로 각 프레임 특징 추출
Dual-level 구조: 프레임 간 차이(local)와 시퀀스 전체 흐름(global)을 동시에 봄
Softmax로 각 프레임이 경계일 확률 출력 → bdy_scores
### 후처리
score pkl 파일로 저장 후 별도로 NMS 적용
NMS window 안에서 최대 score 지점만 남김
>**Non-Maximum Suppression(NMS)**
