## EfficientGEBD
### 입력
mp4 영상을 3프레임마다 1장 샘플링 (60fps → 20fps)
224×224 리사이즈 → ImageNet 정규화
각 프레임마다 앞뒤 10프레임 묶음(window) 을 함께 입력

### 추론
CSN(Channel-Separated Network) 백본으로 시각 특징 추출
각 프레임 위치에서 "전후 장면이 얼마나 다른가"를 비교해 0~1 사이 경계 score 출력

> **CSN(Channel-Separated Network)?**
> 비디오에서 시각 특징을 뽑는 **3D CNN 백본**
> 일반 이미지는 2D CNN(H×W)으로 특징을 뽑는데, 비디오는 시간 축이 추가돼서 3D CNN(H×W×T)이 필요하다. 그래서 CSN 사용


### 후처리
10프레임 window 내 score를 midmax 방식으로 집계 (중간 4프레임의 최대값)
연속으로 threshold(0.35) 넘는 구간을 하나의 그룹으로 묶음
그룹 내 score 최대 지점만 경계로 선택 (group_peaks)

>**midmax**?
>10프레임 중 앞 뒤 3개씩은 제외하고 가운데 4개 중 max값을 사용한다.

### load_video
```python
def load_video(video_path, dim=224, sample_rate=3):
    ## 비디오 열기
    vidcap = cv2.VideoCapture(video_path)
    ## meta 정보가져오기
    nb_frames = int(vidcap.get(cv2.CAP_PROP_FRAME_COUNT))
    fps = vidcap.get(cv2.CAP_PROP_FPS)
    width = vidcap.get(cv2.CAP_PROP_FRAME_WIDTH)  # float
    height = vidcap.get(cv2.CAP_PROP_FRAME_HEIGHT)  # float
    if (width == 0) or (height == 0):
        print(video_path, 'not successfully loaded, drop ..')
        quit()

    images = []
    frame_indices = []
    
    ## 프레임 변환 규칙 준비
    ## 각 프레임에 대해 ToTensor(), ImageNet mean/std 정규화를 적용할 transformer
    transform = transforms.Compose([
        transforms.ToTensor(),
        transforms.Normalize(mean=[0.485, 0.456, 0.406],
                             std=[0.229, 0.224, 0.225])
    ])

    success, image = vidcap.read()
    count = 1
    ## frame을 하나씩 읽으면서 sampling
    while success:
	    ## sample_rate에 해당할때만 처리 sample_rate == 3 -> 1, 4, 7 ....
        if count % sample_rate == 1:
	        ## 선택된 프레임을 모델 입력 형태로 변환
	        ## 사이즈
            image = cv2.resize(image, (dim, dim), interpolation=cv2.INTER_LINEAR)
            ## OpenCV 기본BGR를 RGB로 변환
            image = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)
            ## transform(image)로 적용
            ## 각 frame은 (3, 224, 224) 텐서가 된다.
            images.append(transform(image))
            ## 프레임 번호도 같이 저장
            frame_indices.append(count)
        success, image = vidcap.read()
        count += 1
    vidcap.release()

	## 프레임 리스트를 하나의 텐서로 만들기
    images = torch.stack(images, dim=0)
    ## 최종 Images shape는 (T, 3, 224, 224)
    ## T는 sampling된 frame number
    return images, frame_indices, fps, nb_frames
```

### get_idx_from_score_by_threshold
```python
def get_idx_from_score_by_threshold(threshold=0.5, seq_indices=None, seq_scores=None):
	## 시퀀스 np로 변경하기
    seq_indices = np.array(seq_indices)
    seq_scores = np.array(seq_scores)
    bdy_indices = []
    internals_indices = []
    for i in range(len(seq_scores)):
        if seq_scores[i] >= threshold:
            internals_indices.append(i)
        elif seq_scores[i] < threshold and len(internals_indices) != 0:
            bdy_indices.append(internals_indices)
            internals_indices = []

        if i == len(seq_scores) - 1 and len(internals_indices) != 0:
            bdy_indices.append(internals_indices)

    bdy_indices_in_video = []
    if len(bdy_indices) != 0:
        for internals in bdy_indices:
            center = int(np.mean(internals))
            bdy_indices_in_video.append(seq_indices[center])
    return bdy_indices_in_video
```
